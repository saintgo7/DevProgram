# Download API

## Description
Download RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/download - Get all Downloads
- GET    /api/download/{id} - Get Download by ID
- POST   /api/download - Create new Download
- PUT    /api/download/{id} - Update Download
- DELETE /api/download/{id} - Delete Download

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
