# Customs API

## Description
Customs RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/customs - Get all Customss
- GET    /api/customs/{id} - Get Customs by ID
- POST   /api/customs - Create new Customs
- PUT    /api/customs/{id} - Update Customs
- DELETE /api/customs/{id} - Delete Customs

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
