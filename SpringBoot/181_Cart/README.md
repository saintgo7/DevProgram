# Cart API

## Description
Cart RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/cart - Get all Carts
- GET    /api/cart/{id} - Get Cart by ID
- POST   /api/cart - Create new Cart
- PUT    /api/cart/{id} - Update Cart
- DELETE /api/cart/{id} - Delete Cart

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
