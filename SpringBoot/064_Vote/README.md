# Vote API

## Description
Vote RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/vote - Get all Votes
- GET    /api/vote/{id} - Get Vote by ID
- POST   /api/vote - Create new Vote
- PUT    /api/vote/{id} - Update Vote
- DELETE /api/vote/{id} - Delete Vote

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
