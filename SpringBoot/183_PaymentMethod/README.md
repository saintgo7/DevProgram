# PaymentMethod API

## Description
PaymentMethod RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/paymentmethod - Get all PaymentMethods
- GET    /api/paymentmethod/{id} - Get PaymentMethod by ID
- POST   /api/paymentmethod - Create new PaymentMethod
- PUT    /api/paymentmethod/{id} - Update PaymentMethod
- DELETE /api/paymentmethod/{id} - Delete PaymentMethod

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
