# Answer API

## Description
Answer RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/answer - Get all Answers
- GET    /api/answer/{id} - Get Answer by ID
- POST   /api/answer - Create new Answer
- PUT    /api/answer/{id} - Update Answer
- DELETE /api/answer/{id} - Delete Answer

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
