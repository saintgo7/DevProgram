# Delivery API

## Description
Delivery RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/delivery - Get all Deliverys
- GET    /api/delivery/{id} - Get Delivery by ID
- POST   /api/delivery - Create new Delivery
- PUT    /api/delivery/{id} - Update Delivery
- DELETE /api/delivery/{id} - Delete Delivery

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
