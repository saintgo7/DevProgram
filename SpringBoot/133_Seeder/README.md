# Seeder API

## Description
Seeder RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/seeder - Get all Seeders
- GET    /api/seeder/{id} - Get Seeder by ID
- POST   /api/seeder - Create new Seeder
- PUT    /api/seeder/{id} - Update Seeder
- DELETE /api/seeder/{id} - Delete Seeder

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
