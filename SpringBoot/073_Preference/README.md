# Preference API

## Description
Preference RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/preference - Get all Preferences
- GET    /api/preference/{id} - Get Preference by ID
- POST   /api/preference - Create new Preference
- PUT    /api/preference/{id} - Update Preference
- DELETE /api/preference/{id} - Delete Preference

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
