# Module API

## Description
Module RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/module - Get all Modules
- GET    /api/module/{id} - Get Module by ID
- POST   /api/module - Create new Module
- PUT    /api/module/{id} - Update Module
- DELETE /api/module/{id} - Delete Module

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
