# Search API

## Description
Search RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/search - Get all Searchs
- GET    /api/search/{id} - Get Search by ID
- POST   /api/search - Create new Search
- PUT    /api/search/{id} - Update Search
- DELETE /api/search/{id} - Delete Search

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
