# Route API

## Description
Route RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/route - Get all Routes
- GET    /api/route/{id} - Get Route by ID
- POST   /api/route - Create new Route
- PUT    /api/route/{id} - Update Route
- DELETE /api/route/{id} - Delete Route

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
