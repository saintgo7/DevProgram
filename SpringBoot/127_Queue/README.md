# Queue API

## Description
Queue RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/queue - Get all Queues
- GET    /api/queue/{id} - Get Queue by ID
- POST   /api/queue - Create new Queue
- PUT    /api/queue/{id} - Update Queue
- DELETE /api/queue/{id} - Delete Queue

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
