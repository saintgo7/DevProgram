# Endpoint API

## Description
Endpoint RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/endpoint - Get all Endpoints
- GET    /api/endpoint/{id} - Get Endpoint by ID
- POST   /api/endpoint - Create new Endpoint
- PUT    /api/endpoint/{id} - Update Endpoint
- DELETE /api/endpoint/{id} - Delete Endpoint

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
