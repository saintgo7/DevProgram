# Style API

## Description
Style RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/style - Get all Styles
- GET    /api/style/{id} - Get Style by ID
- POST   /api/style - Create new Style
- PUT    /api/style/{id} - Update Style
- DELETE /api/style/{id} - Delete Style

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
