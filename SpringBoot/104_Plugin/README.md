# Plugin API

## Description
Plugin RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/plugin - Get all Plugins
- GET    /api/plugin/{id} - Get Plugin by ID
- POST   /api/plugin - Create new Plugin
- PUT    /api/plugin/{id} - Update Plugin
- DELETE /api/plugin/{id} - Delete Plugin

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
