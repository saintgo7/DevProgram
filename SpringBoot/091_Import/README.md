# Import API

## Description
Import RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/import - Get all Imports
- GET    /api/import/{id} - Get Import by ID
- POST   /api/import - Create new Import
- PUT    /api/import/{id} - Update Import
- DELETE /api/import/{id} - Delete Import

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
