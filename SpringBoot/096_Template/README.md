# Template API

## Description
Template RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/template - Get all Templates
- GET    /api/template/{id} - Get Template by ID
- POST   /api/template - Create new Template
- PUT    /api/template/{id} - Update Template
- DELETE /api/template/{id} - Delete Template

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
