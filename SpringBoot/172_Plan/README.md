# Plan API

## Description
Plan RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/plan - Get all Plans
- GET    /api/plan/{id} - Get Plan by ID
- POST   /api/plan - Create new Plan
- PUT    /api/plan/{id} - Update Plan
- DELETE /api/plan/{id} - Delete Plan

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
