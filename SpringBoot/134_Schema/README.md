# Schema API

## Description
Schema RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/schema - Get all Schemas
- GET    /api/schema/{id} - Get Schema by ID
- POST   /api/schema - Create new Schema
- PUT    /api/schema/{id} - Update Schema
- DELETE /api/schema/{id} - Delete Schema

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
