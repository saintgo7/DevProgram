# Balance API

## Description
Balance RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/balance - Get all Balances
- GET    /api/balance/{id} - Get Balance by ID
- POST   /api/balance - Create new Balance
- PUT    /api/balance/{id} - Update Balance
- DELETE /api/balance/{id} - Delete Balance

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
