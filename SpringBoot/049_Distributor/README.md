# Distributor API

## Description
Distributor RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/distributor - Get all Distributors
- GET    /api/distributor/{id} - Get Distributor by ID
- POST   /api/distributor - Create new Distributor
- PUT    /api/distributor/{id} - Update Distributor
- DELETE /api/distributor/{id} - Delete Distributor

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
