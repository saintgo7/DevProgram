# Sync API

## Description
Sync RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/sync - Get all Syncs
- GET    /api/sync/{id} - Get Sync by ID
- POST   /api/sync - Create new Sync
- PUT    /api/sync/{id} - Update Sync
- DELETE /api/sync/{id} - Delete Sync

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
