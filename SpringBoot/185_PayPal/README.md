# PayPal API

## Description
PayPal RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/paypal - Get all PayPals
- GET    /api/paypal/{id} - Get PayPal by ID
- POST   /api/paypal - Create new PayPal
- PUT    /api/paypal/{id} - Update PayPal
- DELETE /api/paypal/{id} - Delete PayPal

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
