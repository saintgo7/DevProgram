# Poll API

## Description
Poll RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/poll - Get all Polls
- GET    /api/poll/{id} - Get Poll by ID
- POST   /api/poll - Create new Poll
- PUT    /api/poll/{id} - Update Poll
- DELETE /api/poll/{id} - Delete Poll

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
