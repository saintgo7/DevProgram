# Calendar API

## Description
Calendar RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/calendar - Get all Calendars
- GET    /api/calendar/{id} - Get Calendar by ID
- POST   /api/calendar - Create new Calendar
- PUT    /api/calendar/{id} - Update Calendar
- DELETE /api/calendar/{id} - Delete Calendar

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
