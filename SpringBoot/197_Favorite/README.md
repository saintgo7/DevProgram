# Favorite API

## Description
Favorite RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/favorite - Get all Favorites
- GET    /api/favorite/{id} - Get Favorite by ID
- POST   /api/favorite - Create new Favorite
- PUT    /api/favorite/{id} - Update Favorite
- DELETE /api/favorite/{id} - Delete Favorite

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
