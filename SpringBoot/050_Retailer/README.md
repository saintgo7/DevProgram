# Retailer API

## Description
Retailer RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/retailer - Get all Retailers
- GET    /api/retailer/{id} - Get Retailer by ID
- POST   /api/retailer - Create new Retailer
- PUT    /api/retailer/{id} - Update Retailer
- DELETE /api/retailer/{id} - Delete Retailer

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
