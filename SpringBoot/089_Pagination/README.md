# Pagination API

## Description
Pagination RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/pagination - Get all Paginations
- GET    /api/pagination/{id} - Get Pagination by ID
- POST   /api/pagination - Create new Pagination
- PUT    /api/pagination/{id} - Update Pagination
- DELETE /api/pagination/{id} - Delete Pagination

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
