# Factory API

## Description
Factory RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/factory - Get all Factorys
- GET    /api/factory/{id} - Get Factory by ID
- POST   /api/factory - Create new Factory
- PUT    /api/factory/{id} - Update Factory
- DELETE /api/factory/{id} - Delete Factory

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
