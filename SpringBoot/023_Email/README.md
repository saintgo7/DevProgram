# Email API

## Description
Email RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/email - Get all Emails
- GET    /api/email/{id} - Get Email by ID
- POST   /api/email - Create new Email
- PUT    /api/email/{id} - Update Email
- DELETE /api/email/{id} - Delete Email

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
