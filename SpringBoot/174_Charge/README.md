# Charge API

## Description
Charge RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/charge - Get all Charges
- GET    /api/charge/{id} - Get Charge by ID
- POST   /api/charge - Create new Charge
- PUT    /api/charge/{id} - Update Charge
- DELETE /api/charge/{id} - Delete Charge

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
