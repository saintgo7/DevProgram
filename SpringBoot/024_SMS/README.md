# SMS API

## Description
SMS RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/sms - Get all SMSs
- GET    /api/sms/{id} - Get SMS by ID
- POST   /api/sms - Create new SMS
- PUT    /api/sms/{id} - Update SMS
- DELETE /api/sms/{id} - Delete SMS

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
