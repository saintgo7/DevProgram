# Theme API

## Description
Theme RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/theme - Get all Themes
- GET    /api/theme/{id} - Get Theme by ID
- POST   /api/theme - Create new Theme
- PUT    /api/theme/{id} - Update Theme
- DELETE /api/theme/{id} - Delete Theme

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
