# Inventory API

## Description
Inventory RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/inventory - Get all Inventorys
- GET    /api/inventory/{id} - Get Inventory by ID
- POST   /api/inventory - Create new Inventory
- PUT    /api/inventory/{id} - Update Inventory
- DELETE /api/inventory/{id} - Delete Inventory

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
