# Security API

## Description
Security RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/security - Get all Securitys
- GET    /api/security/{id} - Get Security by ID
- POST   /api/security - Create new Security
- PUT    /api/security/{id} - Update Security
- DELETE /api/security/{id} - Delete Security

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
