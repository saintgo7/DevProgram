# Query API

## Description
Query RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/query - Get all Querys
- GET    /api/query/{id} - Get Query by ID
- POST   /api/query - Create new Query
- PUT    /api/query/{id} - Update Query
- DELETE /api/query/{id} - Delete Query

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
