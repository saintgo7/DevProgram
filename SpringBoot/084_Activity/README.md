# Activity API

## Description
Activity RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/activity - Get all Activitys
- GET    /api/activity/{id} - Get Activity by ID
- POST   /api/activity - Create new Activity
- PUT    /api/activity/{id} - Update Activity
- DELETE /api/activity/{id} - Delete Activity

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
