# Filter API

## Description
Filter RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/filter - Get all Filters
- GET    /api/filter/{id} - Get Filter by ID
- POST   /api/filter - Create new Filter
- PUT    /api/filter/{id} - Update Filter
- DELETE /api/filter/{id} - Delete Filter

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
