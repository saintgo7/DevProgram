# Archive API

## Description
Archive RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/archive - Get all Archives
- GET    /api/archive/{id} - Get Archive by ID
- POST   /api/archive - Create new Archive
- PUT    /api/archive/{id} - Update Archive
- DELETE /api/archive/{id} - Delete Archive

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
