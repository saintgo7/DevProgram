# Article API

## Description
Article RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/article - Get all Articles
- GET    /api/article/{id} - Get Article by ID
- POST   /api/article - Create new Article
- PUT    /api/article/{id} - Update Article
- DELETE /api/article/{id} - Delete Article

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
