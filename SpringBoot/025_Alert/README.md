# Alert API

## Description
Alert RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/alert - Get all Alerts
- GET    /api/alert/{id} - Get Alert by ID
- POST   /api/alert - Create new Alert
- PUT    /api/alert/{id} - Update Alert
- DELETE /api/alert/{id} - Delete Alert

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
