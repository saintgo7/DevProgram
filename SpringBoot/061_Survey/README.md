# Survey API

## Description
Survey RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/survey - Get all Surveys
- GET    /api/survey/{id} - Get Survey by ID
- POST   /api/survey - Create new Survey
- PUT    /api/survey/{id} - Update Survey
- DELETE /api/survey/{id} - Delete Survey

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
