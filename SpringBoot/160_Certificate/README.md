# Certificate API

## Description
Certificate RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/certificate - Get all Certificates
- GET    /api/certificate/{id} - Get Certificate by ID
- POST   /api/certificate - Create new Certificate
- PUT    /api/certificate/{id} - Update Certificate
- DELETE /api/certificate/{id} - Delete Certificate

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
