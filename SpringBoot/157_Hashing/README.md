# Hashing API

## Description
Hashing RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/hashing - Get all Hashings
- GET    /api/hashing/{id} - Get Hashing by ID
- POST   /api/hashing - Create new Hashing
- PUT    /api/hashing/{id} - Update Hashing
- DELETE /api/hashing/{id} - Delete Hashing

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
