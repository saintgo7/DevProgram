# Tracking API

## Description
Tracking RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/tracking - Get all Trackings
- GET    /api/tracking/{id} - Get Tracking by ID
- POST   /api/tracking - Create new Tracking
- PUT    /api/tracking/{id} - Update Tracking
- DELETE /api/tracking/{id} - Delete Tracking

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
