# Stream API

## Description
Stream RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/stream - Get all Streams
- GET    /api/stream/{id} - Get Stream by ID
- POST   /api/stream - Create new Stream
- PUT    /api/stream/{id} - Update Stream
- DELETE /api/stream/{id} - Delete Stream

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
