# Validation API

## Description
Validation RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/validation - Get all Validations
- GET    /api/validation/{id} - Get Validation by ID
- POST   /api/validation - Create new Validation
- PUT    /api/validation/{id} - Update Validation
- DELETE /api/validation/{id} - Delete Validation

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
