# Metric API

## Description
Metric RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/metric - Get all Metrics
- GET    /api/metric/{id} - Get Metric by ID
- POST   /api/metric - Create new Metric
- PUT    /api/metric/{id} - Update Metric
- DELETE /api/metric/{id} - Delete Metric

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
