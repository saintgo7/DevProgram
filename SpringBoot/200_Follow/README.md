# Follow API

## Description
Follow RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/follow - Get all Follows
- GET    /api/follow/{id} - Get Follow by ID
- POST   /api/follow - Create new Follow
- PUT    /api/follow/{id} - Update Follow
- DELETE /api/follow/{id} - Delete Follow

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
