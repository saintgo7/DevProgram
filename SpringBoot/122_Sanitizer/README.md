# Sanitizer API

## Description
Sanitizer RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/sanitizer - Get all Sanitizers
- GET    /api/sanitizer/{id} - Get Sanitizer by ID
- POST   /api/sanitizer - Create new Sanitizer
- PUT    /api/sanitizer/{id} - Update Sanitizer
- DELETE /api/sanitizer/{id} - Delete Sanitizer

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
