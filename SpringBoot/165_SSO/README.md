# SSO API

## Description
SSO RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/sso - Get all SSOs
- GET    /api/sso/{id} - Get SSO by ID
- POST   /api/sso - Create new SSO
- PUT    /api/sso/{id} - Update SSO
- DELETE /api/sso/{id} - Delete SSO

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
