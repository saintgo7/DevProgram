# Transformer API

## Description
Transformer RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/transformer - Get all Transformers
- GET    /api/transformer/{id} - Get Transformer by ID
- POST   /api/transformer - Create new Transformer
- PUT    /api/transformer/{id} - Update Transformer
- DELETE /api/transformer/{id} - Delete Transformer

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
