# Audio API

## Description
Audio RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/audio - Get all Audios
- GET    /api/audio/{id} - Get Audio by ID
- POST   /api/audio - Create new Audio
- PUT    /api/audio/{id} - Update Audio
- DELETE /api/audio/{id} - Delete Audio

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
