# OAuth API

## Description
OAuth RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/oauth - Get all OAuths
- GET    /api/oauth/{id} - Get OAuth by ID
- POST   /api/oauth - Create new OAuth
- PUT    /api/oauth/{id} - Update OAuth
- DELETE /api/oauth/{id} - Delete OAuth

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
