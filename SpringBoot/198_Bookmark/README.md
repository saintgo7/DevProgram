# Bookmark API

## Description
Bookmark RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/bookmark - Get all Bookmarks
- GET    /api/bookmark/{id} - Get Bookmark by ID
- POST   /api/bookmark - Create new Bookmark
- PUT    /api/bookmark/{id} - Update Bookmark
- DELETE /api/bookmark/{id} - Delete Bookmark

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
