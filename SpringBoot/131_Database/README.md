# Database API

## Description
Database RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/database - Get all Databases
- GET    /api/database/{id} - Get Database by ID
- POST   /api/database - Create new Database
- PUT    /api/database/{id} - Update Database
- DELETE /api/database/{id} - Delete Database

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
