# WebSocket API

## Description
WebSocket RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/websocket - Get all WebSockets
- GET    /api/websocket/{id} - Get WebSocket by ID
- POST   /api/websocket - Create new WebSocket
- PUT    /api/websocket/{id} - Update WebSocket
- DELETE /api/websocket/{id} - Delete WebSocket

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
