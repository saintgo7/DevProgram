# Timeline API

## Description
Timeline RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/timeline - Get all Timelines
- GET    /api/timeline/{id} - Get Timeline by ID
- POST   /api/timeline - Create new Timeline
- PUT    /api/timeline/{id} - Update Timeline
- DELETE /api/timeline/{id} - Delete Timeline

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
