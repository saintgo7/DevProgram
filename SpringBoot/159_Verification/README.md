# Verification API

## Description
Verification RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/verification - Get all Verifications
- GET    /api/verification/{id} - Get Verification by ID
- POST   /api/verification - Create new Verification
- PUT    /api/verification/{id} - Update Verification
- DELETE /api/verification/{id} - Delete Verification

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
