# Restore API

## Description
Restore RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/restore - Get all Restores
- GET    /api/restore/{id} - Get Restore by ID
- POST   /api/restore - Create new Restore
- PUT    /api/restore/{id} - Update Restore
- DELETE /api/restore/{id} - Delete Restore

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
