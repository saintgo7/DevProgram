# Discount API

## Description
Discount RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/discount - Get all Discounts
- GET    /api/discount/{id} - Get Discount by ID
- POST   /api/discount - Create new Discount
- PUT    /api/discount/{id} - Update Discount
- DELETE /api/discount/{id} - Delete Discount

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
