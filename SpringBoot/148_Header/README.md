# Header API

## Description
Header RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/header - Get all Headers
- GET    /api/header/{id} - Get Header by ID
- POST   /api/header - Create new Header
- PUT    /api/header/{id} - Update Header
- DELETE /api/header/{id} - Delete Header

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
