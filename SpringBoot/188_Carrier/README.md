# Carrier API

## Description
Carrier RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/carrier - Get all Carriers
- GET    /api/carrier/{id} - Get Carrier by ID
- POST   /api/carrier - Create new Carrier
- PUT    /api/carrier/{id} - Update Carrier
- DELETE /api/carrier/{id} - Delete Carrier

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
