# Widget API

## Description
Widget RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/widget - Get all Widgets
- GET    /api/widget/{id} - Get Widget by ID
- POST   /api/widget - Create new Widget
- PUT    /api/widget/{id} - Update Widget
- DELETE /api/widget/{id} - Delete Widget

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
