# JWT API

## Description
JWT RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/jwt - Get all JWTs
- GET    /api/jwt/{id} - Get JWT by ID
- POST   /api/jwt - Create new JWT
- PUT    /api/jwt/{id} - Update JWT
- DELETE /api/jwt/{id} - Delete JWT

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
