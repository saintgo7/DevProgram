# Cache API

## Description
Cache RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/cache - Get all Caches
- GET    /api/cache/{id} - Get Cache by ID
- POST   /api/cache - Create new Cache
- PUT    /api/cache/{id} - Update Cache
- DELETE /api/cache/{id} - Delete Cache

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
