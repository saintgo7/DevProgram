# Issue API

## Description
Issue RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/issue - Get all Issues
- GET    /api/issue/{id} - Get Issue by ID
- POST   /api/issue - Create new Issue
- PUT    /api/issue/{id} - Update Issue
- DELETE /api/issue/{id} - Delete Issue

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
