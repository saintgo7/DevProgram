# Signing API

## Description
Signing RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/signing - Get all Signings
- GET    /api/signing/{id} - Get Signing by ID
- POST   /api/signing - Create new Signing
- PUT    /api/signing/{id} - Update Signing
- DELETE /api/signing/{id} - Delete Signing

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
