# Duty API

## Description
Duty RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/duty - Get all Dutys
- GET    /api/duty/{id} - Get Duty by ID
- POST   /api/duty - Create new Duty
- PUT    /api/duty/{id} - Update Duty
- DELETE /api/duty/{id} - Delete Duty

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
