# Builder API

## Description
Builder RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/builder - Get all Builders
- GET    /api/builder/{id} - Get Builder by ID
- POST   /api/builder - Create new Builder
- PUT    /api/builder/{id} - Update Builder
- DELETE /api/builder/{id} - Delete Builder

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
