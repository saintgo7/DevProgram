# Audit API

## Description
Audit RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/audit - Get all Audits
- GET    /api/audit/{id} - Get Audit by ID
- POST   /api/audit - Create new Audit
- PUT    /api/audit/{id} - Update Audit
- DELETE /api/audit/{id} - Delete Audit

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
