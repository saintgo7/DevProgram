# Channel API

## Description
Channel RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/channel - Get all Channels
- GET    /api/channel/{id} - Get Channel by ID
- POST   /api/channel - Create new Channel
- PUT    /api/channel/{id} - Update Channel
- DELETE /api/channel/{id} - Delete Channel

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
