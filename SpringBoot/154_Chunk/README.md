# Chunk API

## Description
Chunk RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/chunk - Get all Chunks
- GET    /api/chunk/{id} - Get Chunk by ID
- POST   /api/chunk - Create new Chunk
- PUT    /api/chunk/{id} - Update Chunk
- DELETE /api/chunk/{id} - Delete Chunk

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
