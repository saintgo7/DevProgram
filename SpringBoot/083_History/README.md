# History API

## Description
History RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/history - Get all Historys
- GET    /api/history/{id} - Get History by ID
- POST   /api/history - Create new History
- PUT    /api/history/{id} - Update History
- DELETE /api/history/{id} - Delete History

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
