# Shipment API

## Description
Shipment RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/shipment - Get all Shipments
- GET    /api/shipment/{id} - Get Shipment by ID
- POST   /api/shipment - Create new Shipment
- PUT    /api/shipment/{id} - Update Shipment
- DELETE /api/shipment/{id} - Delete Shipment

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
