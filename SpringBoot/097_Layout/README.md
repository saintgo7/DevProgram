# Layout API

## Description
Layout RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/layout - Get all Layouts
- GET    /api/layout/{id} - Get Layout by ID
- POST   /api/layout - Create new Layout
- PUT    /api/layout/{id} - Update Layout
- DELETE /api/layout/{id} - Delete Layout

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
