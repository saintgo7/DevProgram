# Analytics API

## Description
Analytics RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/analytics - Get all Analyticss
- GET    /api/analytics/{id} - Get Analytics by ID
- POST   /api/analytics - Create new Analytics
- PUT    /api/analytics/{id} - Update Analytics
- DELETE /api/analytics/{id} - Delete Analytics

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
