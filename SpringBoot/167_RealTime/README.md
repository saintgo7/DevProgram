# RealTime API

## Description
RealTime RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/realtime - Get all RealTimes
- GET    /api/realtime/{id} - Get RealTime by ID
- POST   /api/realtime - Create new RealTime
- PUT    /api/realtime/{id} - Update RealTime
- DELETE /api/realtime/{id} - Delete RealTime

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
