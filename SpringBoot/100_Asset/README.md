# Asset API

## Description
Asset RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/asset - Get all Assets
- GET    /api/asset/{id} - Get Asset by ID
- POST   /api/asset - Create new Asset
- PUT    /api/asset/{id} - Update Asset
- DELETE /api/asset/{id} - Delete Asset

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
