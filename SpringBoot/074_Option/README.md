# Option API

## Description
Option RESTful API implementation in SpringBoot.

## Endpoints
- GET    /api/option - Get all Options
- GET    /api/option/{id} - Get Option by ID
- POST   /api/option - Create new Option
- PUT    /api/option/{id} - Update Option
- DELETE /api/option/{id} - Delete Option

## Usage
```bash
mvn spring-boot:run
```

## Features
- RESTful API design
- CRUD operations
- SpringBoot best practices
- JSON responses
