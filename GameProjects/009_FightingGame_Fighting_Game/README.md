# Fighting Game

**Engine**: Unreal

## Features
- Game mechanics
- Player controls
- Score system
- Sound effects & music
- Save/Load system

## Setup
1. Open in Unreal
2. Import assets
3. Build and run

## Controls
- WASD: Movement
- Space: Jump/Action
- Mouse: Aim/Look

## Platform
- Windows, macOS, Linux
- Mobile (iOS/Android)
- WebGL
