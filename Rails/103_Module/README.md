# Module API

## Description
Module RESTful API implementation in Rails.

## Endpoints
- GET    /api/module - Get all Modules
- GET    /api/module/{id} - Get Module by ID
- POST   /api/module - Create new Module
- PUT    /api/module/{id} - Update Module
- DELETE /api/module/{id} - Delete Module

## Usage
```bash
rails server
```

## Features
- RESTful API design
- CRUD operations
- Rails best practices
- JSON responses
