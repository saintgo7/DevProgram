# Offer API

## Description
Offer RESTful API implementation in Rails.

## Endpoints
- GET    /api/offer - Get all Offers
- GET    /api/offer/{id} - Get Offer by ID
- POST   /api/offer - Create new Offer
- PUT    /api/offer/{id} - Update Offer
- DELETE /api/offer/{id} - Delete Offer

## Usage
```bash
rails server
```

## Features
- RESTful API design
- CRUD operations
- Rails best practices
- JSON responses
