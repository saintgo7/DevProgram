# Stream API

## Description
Stream RESTful API implementation in Rails.

## Endpoints
- GET    /api/stream - Get all Streams
- GET    /api/stream/{id} - Get Stream by ID
- POST   /api/stream - Create new Stream
- PUT    /api/stream/{id} - Update Stream
- DELETE /api/stream/{id} - Delete Stream

## Usage
```bash
rails server
```

## Features
- RESTful API design
- CRUD operations
- Rails best practices
- JSON responses
