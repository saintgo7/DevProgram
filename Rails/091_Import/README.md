# Import API

## Description
Import RESTful API implementation in Rails.

## Endpoints
- GET    /api/import - Get all Imports
- GET    /api/import/{id} - Get Import by ID
- POST   /api/import - Create new Import
- PUT    /api/import/{id} - Update Import
- DELETE /api/import/{id} - Delete Import

## Usage
```bash
rails server
```

## Features
- RESTful API design
- CRUD operations
- Rails best practices
- JSON responses
