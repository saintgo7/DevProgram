# Seeder API

## Description
Seeder RESTful API implementation in Rails.

## Endpoints
- GET    /api/seeder - Get all Seeders
- GET    /api/seeder/{id} - Get Seeder by ID
- POST   /api/seeder - Create new Seeder
- PUT    /api/seeder/{id} - Update Seeder
- DELETE /api/seeder/{id} - Delete Seeder

## Usage
```bash
rails server
```

## Features
- RESTful API design
- CRUD operations
- Rails best practices
- JSON responses
