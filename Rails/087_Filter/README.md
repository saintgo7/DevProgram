# Filter API

## Description
Filter RESTful API implementation in Rails.

## Endpoints
- GET    /api/filter - Get all Filters
- GET    /api/filter/{id} - Get Filter by ID
- POST   /api/filter - Create new Filter
- PUT    /api/filter/{id} - Update Filter
- DELETE /api/filter/{id} - Delete Filter

## Usage
```bash
rails server
```

## Features
- RESTful API design
- CRUD operations
- Rails best practices
- JSON responses
