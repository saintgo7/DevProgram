# Widget API

## Description
Widget RESTful API implementation in Rails.

## Endpoints
- GET    /api/widget - Get all Widgets
- GET    /api/widget/{id} - Get Widget by ID
- POST   /api/widget - Create new Widget
- PUT    /api/widget/{id} - Update Widget
- DELETE /api/widget/{id} - Delete Widget

## Usage
```bash
rails server
```

## Features
- RESTful API design
- CRUD operations
- Rails best practices
- JSON responses
