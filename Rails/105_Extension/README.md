# Extension API

## Description
Extension RESTful API implementation in Rails.

## Endpoints
- GET    /api/extension - Get all Extensions
- GET    /api/extension/{id} - Get Extension by ID
- POST   /api/extension - Create new Extension
- PUT    /api/extension/{id} - Update Extension
- DELETE /api/extension/{id} - Delete Extension

## Usage
```bash
rails server
```

## Features
- RESTful API design
- CRUD operations
- Rails best practices
- JSON responses
