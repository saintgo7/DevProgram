# Coupon API

## Description
Coupon RESTful API implementation in Rails.

## Endpoints
- GET    /api/coupon - Get all Coupons
- GET    /api/coupon/{id} - Get Coupon by ID
- POST   /api/coupon - Create new Coupon
- PUT    /api/coupon/{id} - Update Coupon
- DELETE /api/coupon/{id} - Delete Coupon

## Usage
```bash
rails server
```

## Features
- RESTful API design
- CRUD operations
- Rails best practices
- JSON responses
