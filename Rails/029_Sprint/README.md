# Sprint API

## Description
Sprint RESTful API implementation in Rails.

## Endpoints
- GET    /api/sprint - Get all Sprints
- GET    /api/sprint/{id} - Get Sprint by ID
- POST   /api/sprint - Create new Sprint
- PUT    /api/sprint/{id} - Update Sprint
- DELETE /api/sprint/{id} - Delete Sprint

## Usage
```bash
rails server
```

## Features
- RESTful API design
- CRUD operations
- Rails best practices
- JSON responses
