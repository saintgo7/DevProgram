# Error API

## Description
Error RESTful API implementation in Rails.

## Endpoints
- GET    /api/error - Get all Errors
- GET    /api/error/{id} - Get Error by ID
- POST   /api/error - Create new Error
- PUT    /api/error/{id} - Update Error
- DELETE /api/error/{id} - Delete Error

## Usage
```bash
rails server
```

## Features
- RESTful API design
- CRUD operations
- Rails best practices
- JSON responses
