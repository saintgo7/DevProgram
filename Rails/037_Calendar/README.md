# Calendar API

## Description
Calendar RESTful API implementation in Rails.

## Endpoints
- GET    /api/calendar - Get all Calendars
- GET    /api/calendar/{id} - Get Calendar by ID
- POST   /api/calendar - Create new Calendar
- PUT    /api/calendar/{id} - Update Calendar
- DELETE /api/calendar/{id} - Delete Calendar

## Usage
```bash
rails server
```

## Features
- RESTful API design
- CRUD operations
- Rails best practices
- JSON responses
