# Refund API

## Description
Refund RESTful API implementation in Rails.

## Endpoints
- GET    /api/refund - Get all Refunds
- GET    /api/refund/{id} - Get Refund by ID
- POST   /api/refund - Create new Refund
- PUT    /api/refund/{id} - Update Refund
- DELETE /api/refund/{id} - Delete Refund

## Usage
```bash
rails server
```

## Features
- RESTful API design
- CRUD operations
- Rails best practices
- JSON responses
