# Tracking API

## Description
Tracking RESTful API implementation in Rails.

## Endpoints
- GET    /api/tracking - Get all Trackings
- GET    /api/tracking/{id} - Get Tracking by ID
- POST   /api/tracking - Create new Tracking
- PUT    /api/tracking/{id} - Update Tracking
- DELETE /api/tracking/{id} - Delete Tracking

## Usage
```bash
rails server
```

## Features
- RESTful API design
- CRUD operations
- Rails best practices
- JSON responses
