# Graph API

## Description
Graph RESTful API implementation in Rails.

## Endpoints
- GET    /api/graph - Get all Graphs
- GET    /api/graph/{id} - Get Graph by ID
- POST   /api/graph - Create new Graph
- PUT    /api/graph/{id} - Update Graph
- DELETE /api/graph/{id} - Delete Graph

## Usage
```bash
rails server
```

## Features
- RESTful API design
- CRUD operations
- Rails best practices
- JSON responses
