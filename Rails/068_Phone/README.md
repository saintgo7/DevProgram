# Phone API

## Description
Phone RESTful API implementation in Rails.

## Endpoints
- GET    /api/phone - Get all Phones
- GET    /api/phone/{id} - Get Phone by ID
- POST   /api/phone - Create new Phone
- PUT    /api/phone/{id} - Update Phone
- DELETE /api/phone/{id} - Delete Phone

## Usage
```bash
rails server
```

## Features
- RESTful API design
- CRUD operations
- Rails best practices
- JSON responses
