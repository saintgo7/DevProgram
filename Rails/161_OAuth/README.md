# OAuth API

## Description
OAuth RESTful API implementation in Rails.

## Endpoints
- GET    /api/oauth - Get all OAuths
- GET    /api/oauth/{id} - Get OAuth by ID
- POST   /api/oauth - Create new OAuth
- PUT    /api/oauth/{id} - Update OAuth
- DELETE /api/oauth/{id} - Delete OAuth

## Usage
```bash
rails server
```

## Features
- RESTful API design
- CRUD operations
- Rails best practices
- JSON responses
