# Theme API

## Description
Theme RESTful API implementation in Rails.

## Endpoints
- GET    /api/theme - Get all Themes
- GET    /api/theme/{id} - Get Theme by ID
- POST   /api/theme - Create new Theme
- PUT    /api/theme/{id} - Update Theme
- DELETE /api/theme/{id} - Delete Theme

## Usage
```bash
rails server
```

## Features
- RESTful API design
- CRUD operations
- Rails best practices
- JSON responses
