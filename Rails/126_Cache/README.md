# Cache API

## Description
Cache RESTful API implementation in Rails.

## Endpoints
- GET    /api/cache - Get all Caches
- GET    /api/cache/{id} - Get Cache by ID
- POST   /api/cache - Create new Cache
- PUT    /api/cache/{id} - Update Cache
- DELETE /api/cache/{id} - Delete Cache

## Usage
```bash
rails server
```

## Features
- RESTful API design
- CRUD operations
- Rails best practices
- JSON responses
