# SSO API

## Description
SSO RESTful API implementation in Rails.

## Endpoints
- GET    /api/sso - Get all SSOs
- GET    /api/sso/{id} - Get SSO by ID
- POST   /api/sso - Create new SSO
- PUT    /api/sso/{id} - Update SSO
- DELETE /api/sso/{id} - Delete SSO

## Usage
```bash
rails server
```

## Features
- RESTful API design
- CRUD operations
- Rails best practices
- JSON responses
