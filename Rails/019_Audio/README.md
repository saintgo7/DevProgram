# Audio API

## Description
Audio RESTful API implementation in Rails.

## Endpoints
- GET    /api/audio - Get all Audios
- GET    /api/audio/{id} - Get Audio by ID
- POST   /api/audio - Create new Audio
- PUT    /api/audio/{id} - Update Audio
- DELETE /api/audio/{id} - Delete Audio

## Usage
```bash
rails server
```

## Features
- RESTful API design
- CRUD operations
- Rails best practices
- JSON responses
