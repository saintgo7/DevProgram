# Join API

## Description
Join RESTful API implementation in Rails.

## Endpoints
- GET    /api/join - Get all Joins
- GET    /api/join/{id} - Get Join by ID
- POST   /api/join - Create new Join
- PUT    /api/join/{id} - Update Join
- DELETE /api/join/{id} - Delete Join

## Usage
```bash
rails server
```

## Features
- RESTful API design
- CRUD operations
- Rails best practices
- JSON responses
