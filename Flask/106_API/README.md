# API API

## Description
API RESTful API implementation in Flask.

## Endpoints
- GET    /api/api - Get all APIs
- GET    /api/api/{id} - Get API by ID
- POST   /api/api - Create new API
- PUT    /api/api/{id} - Update API
- DELETE /api/api/{id} - Delete API

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
