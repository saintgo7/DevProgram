# Survey API

## Description
Survey RESTful API implementation in Flask.

## Endpoints
- GET    /api/survey - Get all Surveys
- GET    /api/survey/{id} - Get Survey by ID
- POST   /api/survey - Create new Survey
- PUT    /api/survey/{id} - Update Survey
- DELETE /api/survey/{id} - Delete Survey

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
