# Query API

## Description
Query RESTful API implementation in Flask.

## Endpoints
- GET    /api/query - Get all Querys
- GET    /api/query/{id} - Get Query by ID
- POST   /api/query - Create new Query
- PUT    /api/query/{id} - Update Query
- DELETE /api/query/{id} - Delete Query

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
