# Video API

## Description
Video RESTful API implementation in Flask.

## Endpoints
- GET    /api/video - Get all Videos
- GET    /api/video/{id} - Get Video by ID
- POST   /api/video - Create new Video
- PUT    /api/video/{id} - Update Video
- DELETE /api/video/{id} - Delete Video

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
