# Log API

## Description
Log RESTful API implementation in Flask.

## Endpoints
- GET    /api/log - Get all Logs
- GET    /api/log/{id} - Get Log by ID
- POST   /api/log - Create new Log
- PUT    /api/log/{id} - Update Log
- DELETE /api/log/{id} - Delete Log

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
