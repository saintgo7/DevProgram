# Download API

## Description
Download RESTful API implementation in Flask.

## Endpoints
- GET    /api/download - Get all Downloads
- GET    /api/download/{id} - Get Download by ID
- POST   /api/download - Create new Download
- PUT    /api/download/{id} - Update Download
- DELETE /api/download/{id} - Delete Download

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
