# Audit API

## Description
Audit RESTful API implementation in Flask.

## Endpoints
- GET    /api/audit - Get all Audits
- GET    /api/audit/{id} - Get Audit by ID
- POST   /api/audit - Create new Audit
- PUT    /api/audit/{id} - Update Audit
- DELETE /api/audit/{id} - Delete Audit

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
