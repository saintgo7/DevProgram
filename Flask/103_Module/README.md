# Module API

## Description
Module RESTful API implementation in Flask.

## Endpoints
- GET    /api/module - Get all Modules
- GET    /api/module/{id} - Get Module by ID
- POST   /api/module - Create new Module
- PUT    /api/module/{id} - Update Module
- DELETE /api/module/{id} - Delete Module

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
