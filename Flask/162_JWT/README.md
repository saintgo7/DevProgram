# JWT API

## Description
JWT RESTful API implementation in Flask.

## Endpoints
- GET    /api/jwt - Get all JWTs
- GET    /api/jwt/{id} - Get JWT by ID
- POST   /api/jwt - Create new JWT
- PUT    /api/jwt/{id} - Update JWT
- DELETE /api/jwt/{id} - Delete JWT

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
