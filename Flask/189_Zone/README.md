# Zone API

## Description
Zone RESTful API implementation in Flask.

## Endpoints
- GET    /api/zone - Get all Zones
- GET    /api/zone/{id} - Get Zone by ID
- POST   /api/zone - Create new Zone
- PUT    /api/zone/{id} - Update Zone
- DELETE /api/zone/{id} - Delete Zone

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
