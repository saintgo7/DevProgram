# Option API

## Description
Option RESTful API implementation in Flask.

## Endpoints
- GET    /api/option - Get all Options
- GET    /api/option/{id} - Get Option by ID
- POST   /api/option - Create new Option
- PUT    /api/option/{id} - Update Option
- DELETE /api/option/{id} - Delete Option

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
