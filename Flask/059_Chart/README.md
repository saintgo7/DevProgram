# Chart API

## Description
Chart RESTful API implementation in Flask.

## Endpoints
- GET    /api/chart - Get all Charts
- GET    /api/chart/{id} - Get Chart by ID
- POST   /api/chart - Create new Chart
- PUT    /api/chart/{id} - Update Chart
- DELETE /api/chart/{id} - Delete Chart

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
