# Filter API

## Description
Filter RESTful API implementation in Flask.

## Endpoints
- GET    /api/filter - Get all Filters
- GET    /api/filter/{id} - Get Filter by ID
- POST   /api/filter - Create new Filter
- PUT    /api/filter/{id} - Update Filter
- DELETE /api/filter/{id} - Delete Filter

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
