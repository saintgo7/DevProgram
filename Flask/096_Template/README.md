# Template API

## Description
Template RESTful API implementation in Flask.

## Endpoints
- GET    /api/template - Get all Templates
- GET    /api/template/{id} - Get Template by ID
- POST   /api/template - Create new Template
- PUT    /api/template/{id} - Update Template
- DELETE /api/template/{id} - Delete Template

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
