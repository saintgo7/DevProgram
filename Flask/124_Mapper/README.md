# Mapper API

## Description
Mapper RESTful API implementation in Flask.

## Endpoints
- GET    /api/mapper - Get all Mappers
- GET    /api/mapper/{id} - Get Mapper by ID
- POST   /api/mapper - Create new Mapper
- PUT    /api/mapper/{id} - Update Mapper
- DELETE /api/mapper/{id} - Delete Mapper

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
