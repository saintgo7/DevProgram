# Theme API

## Description
Theme RESTful API implementation in Flask.

## Endpoints
- GET    /api/theme - Get all Themes
- GET    /api/theme/{id} - Get Theme by ID
- POST   /api/theme - Create new Theme
- PUT    /api/theme/{id} - Update Theme
- DELETE /api/theme/{id} - Delete Theme

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
