# Photo API

## Description
Photo RESTful API implementation in Flask.

## Endpoints
- GET    /api/photo - Get all Photos
- GET    /api/photo/{id} - Get Photo by ID
- POST   /api/photo - Create new Photo
- PUT    /api/photo/{id} - Update Photo
- DELETE /api/photo/{id} - Delete Photo

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
