# Buffer API

## Description
Buffer RESTful API implementation in Flask.

## Endpoints
- GET    /api/buffer - Get all Buffers
- GET    /api/buffer/{id} - Get Buffer by ID
- POST   /api/buffer - Create new Buffer
- PUT    /api/buffer/{id} - Update Buffer
- DELETE /api/buffer/{id} - Delete Buffer

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
