# Model API

## Description
Model RESTful API implementation in Flask.

## Endpoints
- GET    /api/model - Get all Models
- GET    /api/model/{id} - Get Model by ID
- POST   /api/model - Create new Model
- PUT    /api/model/{id} - Update Model
- DELETE /api/model/{id} - Delete Model

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
