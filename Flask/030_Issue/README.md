# Issue API

## Description
Issue RESTful API implementation in Flask.

## Endpoints
- GET    /api/issue - Get all Issues
- GET    /api/issue/{id} - Get Issue by ID
- POST   /api/issue - Create new Issue
- PUT    /api/issue/{id} - Update Issue
- DELETE /api/issue/{id} - Delete Issue

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
