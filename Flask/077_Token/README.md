# Token API

## Description
Token RESTful API implementation in Flask.

## Endpoints
- GET    /api/token - Get all Tokens
- GET    /api/token/{id} - Get Token by ID
- POST   /api/token - Create new Token
- PUT    /api/token/{id} - Update Token
- DELETE /api/token/{id} - Delete Token

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
