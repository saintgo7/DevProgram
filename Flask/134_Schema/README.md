# Schema API

## Description
Schema RESTful API implementation in Flask.

## Endpoints
- GET    /api/schema - Get all Schemas
- GET    /api/schema/{id} - Get Schema by ID
- POST   /api/schema - Create new Schema
- PUT    /api/schema/{id} - Update Schema
- DELETE /api/schema/{id} - Delete Schema

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
