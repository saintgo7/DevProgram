# Response API

## Description
Response RESTful API implementation in Flask.

## Endpoints
- GET    /api/response - Get all Responses
- GET    /api/response/{id} - Get Response by ID
- POST   /api/response - Create new Response
- PUT    /api/response/{id} - Update Response
- DELETE /api/response/{id} - Delete Response

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
