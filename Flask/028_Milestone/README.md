# Milestone API

## Description
Milestone RESTful API implementation in Flask.

## Endpoints
- GET    /api/milestone - Get all Milestones
- GET    /api/milestone/{id} - Get Milestone by ID
- POST   /api/milestone - Create new Milestone
- PUT    /api/milestone/{id} - Update Milestone
- DELETE /api/milestone/{id} - Delete Milestone

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
