# Poll API

## Description
Poll RESTful API implementation in Flask.

## Endpoints
- GET    /api/poll - Get all Polls
- GET    /api/poll/{id} - Get Poll by ID
- POST   /api/poll - Create new Poll
- PUT    /api/poll/{id} - Update Poll
- DELETE /api/poll/{id} - Delete Poll

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
