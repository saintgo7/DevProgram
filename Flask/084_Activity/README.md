# Activity API

## Description
Activity RESTful API implementation in Flask.

## Endpoints
- GET    /api/activity - Get all Activitys
- GET    /api/activity/{id} - Get Activity by ID
- POST   /api/activity - Create new Activity
- PUT    /api/activity/{id} - Update Activity
- DELETE /api/activity/{id} - Delete Activity

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
