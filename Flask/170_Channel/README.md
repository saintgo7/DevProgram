# Channel API

## Description
Channel RESTful API implementation in Flask.

## Endpoints
- GET    /api/channel - Get all Channels
- GET    /api/channel/{id} - Get Channel by ID
- POST   /api/channel - Create new Channel
- PUT    /api/channel/{id} - Update Channel
- DELETE /api/channel/{id} - Delete Channel

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
