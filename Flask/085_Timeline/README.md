# Timeline API

## Description
Timeline RESTful API implementation in Flask.

## Endpoints
- GET    /api/timeline - Get all Timelines
- GET    /api/timeline/{id} - Get Timeline by ID
- POST   /api/timeline - Create new Timeline
- PUT    /api/timeline/{id} - Update Timeline
- DELETE /api/timeline/{id} - Delete Timeline

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
