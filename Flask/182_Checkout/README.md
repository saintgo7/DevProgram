# Checkout API

## Description
Checkout RESTful API implementation in Flask.

## Endpoints
- GET    /api/checkout - Get all Checkouts
- GET    /api/checkout/{id} - Get Checkout by ID
- POST   /api/checkout - Create new Checkout
- PUT    /api/checkout/{id} - Update Checkout
- DELETE /api/checkout/{id} - Delete Checkout

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
