# Route API

## Description
Route RESTful API implementation in Flask.

## Endpoints
- GET    /api/route - Get all Routes
- GET    /api/route/{id} - Get Route by ID
- POST   /api/route - Create new Route
- PUT    /api/route/{id} - Update Route
- DELETE /api/route/{id} - Delete Route

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
