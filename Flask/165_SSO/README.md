# SSO API

## Description
SSO RESTful API implementation in Flask.

## Endpoints
- GET    /api/sso - Get all SSOs
- GET    /api/sso/{id} - Get SSO by ID
- POST   /api/sso - Create new SSO
- PUT    /api/sso/{id} - Update SSO
- DELETE /api/sso/{id} - Delete SSO

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
