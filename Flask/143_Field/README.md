# Field API

## Description
Field RESTful API implementation in Flask.

## Endpoints
- GET    /api/field - Get all Fields
- GET    /api/field/{id} - Get Field by ID
- POST   /api/field - Create new Field
- PUT    /api/field/{id} - Update Field
- DELETE /api/field/{id} - Delete Field

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
