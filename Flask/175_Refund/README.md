# Refund API

## Description
Refund RESTful API implementation in Flask.

## Endpoints
- GET    /api/refund - Get all Refunds
- GET    /api/refund/{id} - Get Refund by ID
- POST   /api/refund - Create new Refund
- PUT    /api/refund/{id} - Update Refund
- DELETE /api/refund/{id} - Delete Refund

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
