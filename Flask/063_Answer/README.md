# Answer API

## Description
Answer RESTful API implementation in Flask.

## Endpoints
- GET    /api/answer - Get all Answers
- GET    /api/answer/{id} - Get Answer by ID
- POST   /api/answer - Create new Answer
- PUT    /api/answer/{id} - Update Answer
- DELETE /api/answer/{id} - Delete Answer

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
