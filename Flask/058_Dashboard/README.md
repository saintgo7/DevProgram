# Dashboard API

## Description
Dashboard RESTful API implementation in Flask.

## Endpoints
- GET    /api/dashboard - Get all Dashboards
- GET    /api/dashboard/{id} - Get Dashboard by ID
- POST   /api/dashboard - Create new Dashboard
- PUT    /api/dashboard/{id} - Update Dashboard
- DELETE /api/dashboard/{id} - Delete Dashboard

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
