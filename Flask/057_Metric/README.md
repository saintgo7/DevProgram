# Metric API

## Description
Metric RESTful API implementation in Flask.

## Endpoints
- GET    /api/metric - Get all Metrics
- GET    /api/metric/{id} - Get Metric by ID
- POST   /api/metric - Create new Metric
- PUT    /api/metric/{id} - Update Metric
- DELETE /api/metric/{id} - Delete Metric

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
