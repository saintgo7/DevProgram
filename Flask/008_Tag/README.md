# Tag API

## Description
Tag RESTful API implementation in Flask.

## Endpoints
- GET    /api/tag - Get all Tags
- GET    /api/tag/{id} - Get Tag by ID
- POST   /api/tag - Create new Tag
- PUT    /api/tag/{id} - Update Tag
- DELETE /api/tag/{id} - Delete Tag

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
