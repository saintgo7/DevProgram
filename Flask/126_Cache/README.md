# Cache API

## Description
Cache RESTful API implementation in Flask.

## Endpoints
- GET    /api/cache - Get all Caches
- GET    /api/cache/{id} - Get Cache by ID
- POST   /api/cache - Create new Cache
- PUT    /api/cache/{id} - Update Cache
- DELETE /api/cache/{id} - Delete Cache

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
