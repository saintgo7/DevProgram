# Tax API

## Description
Tax RESTful API implementation in Flask.

## Endpoints
- GET    /api/tax - Get all Taxs
- GET    /api/tax/{id} - Get Tax by ID
- POST   /api/tax - Create new Tax
- PUT    /api/tax/{id} - Update Tax
- DELETE /api/tax/{id} - Delete Tax

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
