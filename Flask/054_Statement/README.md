# Statement API

## Description
Statement RESTful API implementation in Flask.

## Endpoints
- GET    /api/statement - Get all Statements
- GET    /api/statement/{id} - Get Statement by ID
- POST   /api/statement - Create new Statement
- PUT    /api/statement/{id} - Update Statement
- DELETE /api/statement/{id} - Delete Statement

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
