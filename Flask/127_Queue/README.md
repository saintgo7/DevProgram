# Queue API

## Description
Queue RESTful API implementation in Flask.

## Endpoints
- GET    /api/queue - Get all Queues
- GET    /api/queue/{id} - Get Queue by ID
- POST   /api/queue - Create new Queue
- PUT    /api/queue/{id} - Update Queue
- DELETE /api/queue/{id} - Delete Queue

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
