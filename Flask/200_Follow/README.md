# Follow API

## Description
Follow RESTful API implementation in Flask.

## Endpoints
- GET    /api/follow - Get all Follows
- GET    /api/follow/{id} - Get Follow by ID
- POST   /api/follow - Create new Follow
- PUT    /api/follow/{id} - Update Follow
- DELETE /api/follow/{id} - Delete Follow

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
