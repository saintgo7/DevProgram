# Sort API

## Description
Sort RESTful API implementation in Flask.

## Endpoints
- GET    /api/sort - Get all Sorts
- GET    /api/sort/{id} - Get Sort by ID
- POST   /api/sort - Create new Sort
- PUT    /api/sort/{id} - Update Sort
- DELETE /api/sort/{id} - Delete Sort

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
