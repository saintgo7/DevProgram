# Email API

## Description
Email RESTful API implementation in Flask.

## Endpoints
- GET    /api/email - Get all Emails
- GET    /api/email/{id} - Get Email by ID
- POST   /api/email - Create new Email
- PUT    /api/email/{id} - Update Email
- DELETE /api/email/{id} - Delete Email

## Usage
```bash
python app.py
```

## Features
- RESTful API design
- CRUD operations
- Flask best practices
- JSON responses
