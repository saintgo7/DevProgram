# Route API

## Description
Route RESTful API implementation in Gin.

## Endpoints
- GET    /api/route - Get all Routes
- GET    /api/route/{id} - Get Route by ID
- POST   /api/route - Create new Route
- PUT    /api/route/{id} - Update Route
- DELETE /api/route/{id} - Delete Route

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
