# Review API

## Description
Review RESTful API implementation in Gin.

## Endpoints
- GET    /api/review - Get all Reviews
- GET    /api/review/{id} - Get Review by ID
- POST   /api/review - Create new Review
- PUT    /api/review/{id} - Update Review
- DELETE /api/review/{id} - Delete Review

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
