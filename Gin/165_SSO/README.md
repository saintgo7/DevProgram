# SSO API

## Description
SSO RESTful API implementation in Gin.

## Endpoints
- GET    /api/sso - Get all SSOs
- GET    /api/sso/{id} - Get SSO by ID
- POST   /api/sso - Create new SSO
- PUT    /api/sso/{id} - Update SSO
- DELETE /api/sso/{id} - Delete SSO

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
