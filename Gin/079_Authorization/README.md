# Authorization API

## Description
Authorization RESTful API implementation in Gin.

## Endpoints
- GET    /api/authorization - Get all Authorizations
- GET    /api/authorization/{id} - Get Authorization by ID
- POST   /api/authorization - Create new Authorization
- PUT    /api/authorization/{id} - Update Authorization
- DELETE /api/authorization/{id} - Delete Authorization

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
