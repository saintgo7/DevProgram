# Association API

## Description
Association RESTful API implementation in Gin.

## Endpoints
- GET    /api/association - Get all Associations
- GET    /api/association/{id} - Get Association by ID
- POST   /api/association - Create new Association
- PUT    /api/association/{id} - Update Association
- DELETE /api/association/{id} - Delete Association

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
