# File API

## Description
File RESTful API implementation in Gin.

## Endpoints
- GET    /api/file - Get all Files
- GET    /api/file/{id} - Get File by ID
- POST   /api/file - Create new File
- PUT    /api/file/{id} - Update File
- DELETE /api/file/{id} - Delete File

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
