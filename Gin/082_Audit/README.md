# Audit API

## Description
Audit RESTful API implementation in Gin.

## Endpoints
- GET    /api/audit - Get all Audits
- GET    /api/audit/{id} - Get Audit by ID
- POST   /api/audit - Create new Audit
- PUT    /api/audit/{id} - Update Audit
- DELETE /api/audit/{id} - Delete Audit

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
