# SMS API

## Description
SMS RESTful API implementation in Gin.

## Endpoints
- GET    /api/sms - Get all SMSs
- GET    /api/sms/{id} - Get SMS by ID
- POST   /api/sms - Create new SMS
- PUT    /api/sms/{id} - Update SMS
- DELETE /api/sms/{id} - Delete SMS

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
