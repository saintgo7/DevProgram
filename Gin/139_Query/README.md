# Query API

## Description
Query RESTful API implementation in Gin.

## Endpoints
- GET    /api/query - Get all Querys
- GET    /api/query/{id} - Get Query by ID
- POST   /api/query - Create new Query
- PUT    /api/query/{id} - Update Query
- DELETE /api/query/{id} - Delete Query

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
