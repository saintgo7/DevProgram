# Queue API

## Description
Queue RESTful API implementation in Gin.

## Endpoints
- GET    /api/queue - Get all Queues
- GET    /api/queue/{id} - Get Queue by ID
- POST   /api/queue - Create new Queue
- PUT    /api/queue/{id} - Update Queue
- DELETE /api/queue/{id} - Delete Queue

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
