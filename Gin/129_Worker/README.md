# Worker API

## Description
Worker RESTful API implementation in Gin.

## Endpoints
- GET    /api/worker - Get all Workers
- GET    /api/worker/{id} - Get Worker by ID
- POST   /api/worker - Create new Worker
- PUT    /api/worker/{id} - Update Worker
- DELETE /api/worker/{id} - Delete Worker

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
