# Bookmark API

## Description
Bookmark RESTful API implementation in Gin.

## Endpoints
- GET    /api/bookmark - Get all Bookmarks
- GET    /api/bookmark/{id} - Get Bookmark by ID
- POST   /api/bookmark - Create new Bookmark
- PUT    /api/bookmark/{id} - Update Bookmark
- DELETE /api/bookmark/{id} - Delete Bookmark

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
