# Error API

## Description
Error RESTful API implementation in Gin.

## Endpoints
- GET    /api/error - Get all Errors
- GET    /api/error/{id} - Get Error by ID
- POST   /api/error - Create new Error
- PUT    /api/error/{id} - Update Error
- DELETE /api/error/{id} - Delete Error

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
