# Relationship API

## Description
Relationship RESTful API implementation in Gin.

## Endpoints
- GET    /api/relationship - Get all Relationships
- GET    /api/relationship/{id} - Get Relationship by ID
- POST   /api/relationship - Create new Relationship
- PUT    /api/relationship/{id} - Update Relationship
- DELETE /api/relationship/{id} - Delete Relationship

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
