# Member API

## Description
Member RESTful API implementation in Gin.

## Endpoints
- GET    /api/member - Get all Members
- GET    /api/member/{id} - Get Member by ID
- POST   /api/member - Create new Member
- PUT    /api/member/{id} - Update Member
- DELETE /api/member/{id} - Delete Member

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
