# Delivery API

## Description
Delivery RESTful API implementation in Gin.

## Endpoints
- GET    /api/delivery - Get all Deliverys
- GET    /api/delivery/{id} - Get Delivery by ID
- POST   /api/delivery - Create new Delivery
- PUT    /api/delivery/{id} - Update Delivery
- DELETE /api/delivery/{id} - Delete Delivery

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
