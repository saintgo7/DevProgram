# Seeder API

## Description
Seeder RESTful API implementation in Gin.

## Endpoints
- GET    /api/seeder - Get all Seeders
- GET    /api/seeder/{id} - Get Seeder by ID
- POST   /api/seeder - Create new Seeder
- PUT    /api/seeder/{id} - Update Seeder
- DELETE /api/seeder/{id} - Delete Seeder

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
