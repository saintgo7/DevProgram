# Header API

## Description
Header RESTful API implementation in Gin.

## Endpoints
- GET    /api/header - Get all Headers
- GET    /api/header/{id} - Get Header by ID
- POST   /api/header - Create new Header
- PUT    /api/header/{id} - Update Header
- DELETE /api/header/{id} - Delete Header

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
