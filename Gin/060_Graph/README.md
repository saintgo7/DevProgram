# Graph API

## Description
Graph RESTful API implementation in Gin.

## Endpoints
- GET    /api/graph - Get all Graphs
- GET    /api/graph/{id} - Get Graph by ID
- POST   /api/graph - Create new Graph
- PUT    /api/graph/{id} - Update Graph
- DELETE /api/graph/{id} - Delete Graph

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
