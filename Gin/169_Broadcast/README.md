# Broadcast API

## Description
Broadcast RESTful API implementation in Gin.

## Endpoints
- GET    /api/broadcast - Get all Broadcasts
- GET    /api/broadcast/{id} - Get Broadcast by ID
- POST   /api/broadcast - Create new Broadcast
- PUT    /api/broadcast/{id} - Update Broadcast
- DELETE /api/broadcast/{id} - Delete Broadcast

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
