# User API

## Description
User RESTful API implementation in Gin.

## Endpoints
- GET    /api/user - Get all Users
- GET    /api/user/{id} - Get User by ID
- POST   /api/user - Create new User
- PUT    /api/user/{id} - Update User
- DELETE /api/user/{id} - Delete User

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
