# Photo API

## Description
Photo RESTful API implementation in Gin.

## Endpoints
- GET    /api/photo - Get all Photos
- GET    /api/photo/{id} - Get Photo by ID
- POST   /api/photo - Create new Photo
- PUT    /api/photo/{id} - Update Photo
- DELETE /api/photo/{id} - Delete Photo

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
