# Zone API

## Description
Zone RESTful API implementation in Gin.

## Endpoints
- GET    /api/zone - Get all Zones
- GET    /api/zone/{id} - Get Zone by ID
- POST   /api/zone - Create new Zone
- PUT    /api/zone/{id} - Update Zone
- DELETE /api/zone/{id} - Delete Zone

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
