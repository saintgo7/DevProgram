# Balance API

## Description
Balance RESTful API implementation in Gin.

## Endpoints
- GET    /api/balance - Get all Balances
- GET    /api/balance/{id} - Get Balance by ID
- POST   /api/balance - Create new Balance
- PUT    /api/balance/{id} - Update Balance
- DELETE /api/balance/{id} - Delete Balance

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
