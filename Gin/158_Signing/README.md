# Signing API

## Description
Signing RESTful API implementation in Gin.

## Endpoints
- GET    /api/signing - Get all Signings
- GET    /api/signing/{id} - Get Signing by ID
- POST   /api/signing - Create new Signing
- PUT    /api/signing/{id} - Update Signing
- DELETE /api/signing/{id} - Delete Signing

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
