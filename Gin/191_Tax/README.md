# Tax API

## Description
Tax RESTful API implementation in Gin.

## Endpoints
- GET    /api/tax - Get all Taxs
- GET    /api/tax/{id} - Get Tax by ID
- POST   /api/tax - Create new Tax
- PUT    /api/tax/{id} - Update Tax
- DELETE /api/tax/{id} - Delete Tax

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
