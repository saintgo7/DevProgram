# Retailer API

## Description
Retailer RESTful API implementation in Gin.

## Endpoints
- GET    /api/retailer - Get all Retailers
- GET    /api/retailer/{id} - Get Retailer by ID
- POST   /api/retailer - Create new Retailer
- PUT    /api/retailer/{id} - Update Retailer
- DELETE /api/retailer/{id} - Delete Retailer

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
