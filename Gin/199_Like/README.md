# Like API

## Description
Like RESTful API implementation in Gin.

## Endpoints
- GET    /api/like - Get all Likes
- GET    /api/like/{id} - Get Like by ID
- POST   /api/like - Create new Like
- PUT    /api/like/{id} - Update Like
- DELETE /api/like/{id} - Delete Like

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
