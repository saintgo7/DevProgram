# Coupon API

## Description
Coupon RESTful API implementation in Gin.

## Endpoints
- GET    /api/coupon - Get all Coupons
- GET    /api/coupon/{id} - Get Coupon by ID
- POST   /api/coupon - Create new Coupon
- PUT    /api/coupon/{id} - Update Coupon
- DELETE /api/coupon/{id} - Delete Coupon

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
