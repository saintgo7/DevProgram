# Event API

## Description
Event RESTful API implementation in Gin.

## Endpoints
- GET    /api/event - Get all Events
- GET    /api/event/{id} - Get Event by ID
- POST   /api/event - Create new Event
- PUT    /api/event/{id} - Update Event
- DELETE /api/event/{id} - Delete Event

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
