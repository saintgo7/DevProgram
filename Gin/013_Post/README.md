# Post API

## Description
Post RESTful API implementation in Gin.

## Endpoints
- GET    /api/post - Get all Posts
- GET    /api/post/{id} - Get Post by ID
- POST   /api/post - Create new Post
- PUT    /api/post/{id} - Update Post
- DELETE /api/post/{id} - Delete Post

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
