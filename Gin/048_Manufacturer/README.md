# Manufacturer API

## Description
Manufacturer RESTful API implementation in Gin.

## Endpoints
- GET    /api/manufacturer - Get all Manufacturers
- GET    /api/manufacturer/{id} - Get Manufacturer by ID
- POST   /api/manufacturer - Create new Manufacturer
- PUT    /api/manufacturer/{id} - Update Manufacturer
- DELETE /api/manufacturer/{id} - Delete Manufacturer

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
