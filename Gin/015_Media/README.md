# Media API

## Description
Media RESTful API implementation in Gin.

## Endpoints
- GET    /api/media - Get all Medias
- GET    /api/media/{id} - Get Media by ID
- POST   /api/media - Create new Media
- PUT    /api/media/{id} - Update Media
- DELETE /api/media/{id} - Delete Media

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
