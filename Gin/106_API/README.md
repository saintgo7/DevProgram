# API API

## Description
API RESTful API implementation in Gin.

## Endpoints
- GET    /api/api - Get all APIs
- GET    /api/api/{id} - Get API by ID
- POST   /api/api - Create new API
- PUT    /api/api/{id} - Update API
- DELETE /api/api/{id} - Delete API

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
