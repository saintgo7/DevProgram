# Authentication API

## Description
Authentication RESTful API implementation in Gin.

## Endpoints
- GET    /api/authentication - Get all Authentications
- GET    /api/authentication/{id} - Get Authentication by ID
- POST   /api/authentication - Create new Authentication
- PUT    /api/authentication/{id} - Update Authentication
- DELETE /api/authentication/{id} - Delete Authentication

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
