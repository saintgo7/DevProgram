# Migration API

## Description
Migration RESTful API implementation in Gin.

## Endpoints
- GET    /api/migration - Get all Migrations
- GET    /api/migration/{id} - Get Migration by ID
- POST   /api/migration - Create new Migration
- PUT    /api/migration/{id} - Update Migration
- DELETE /api/migration/{id} - Delete Migration

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
