# Pusher API

## Description
Pusher RESTful API implementation in Gin.

## Endpoints
- GET    /api/pusher - Get all Pushers
- GET    /api/pusher/{id} - Get Pusher by ID
- POST   /api/pusher - Create new Pusher
- PUT    /api/pusher/{id} - Update Pusher
- DELETE /api/pusher/{id} - Delete Pusher

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
