# RealTime API

## Description
RealTime RESTful API implementation in Gin.

## Endpoints
- GET    /api/realtime - Get all RealTimes
- GET    /api/realtime/{id} - Get RealTime by ID
- POST   /api/realtime - Create new RealTime
- PUT    /api/realtime/{id} - Update RealTime
- DELETE /api/realtime/{id} - Delete RealTime

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
