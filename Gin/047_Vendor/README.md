# Vendor API

## Description
Vendor RESTful API implementation in Gin.

## Endpoints
- GET    /api/vendor - Get all Vendors
- GET    /api/vendor/{id} - Get Vendor by ID
- POST   /api/vendor - Create new Vendor
- PUT    /api/vendor/{id} - Update Vendor
- DELETE /api/vendor/{id} - Delete Vendor

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
