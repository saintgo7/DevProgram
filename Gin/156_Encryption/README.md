# Encryption API

## Description
Encryption RESTful API implementation in Gin.

## Endpoints
- GET    /api/encryption - Get all Encryptions
- GET    /api/encryption/{id} - Get Encryption by ID
- POST   /api/encryption - Create new Encryption
- PUT    /api/encryption/{id} - Update Encryption
- DELETE /api/encryption/{id} - Delete Encryption

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
