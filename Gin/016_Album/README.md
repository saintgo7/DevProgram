# Album API

## Description
Album RESTful API implementation in Gin.

## Endpoints
- GET    /api/album - Get all Albums
- GET    /api/album/{id} - Get Album by ID
- POST   /api/album - Create new Album
- PUT    /api/album/{id} - Update Album
- DELETE /api/album/{id} - Delete Album

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
