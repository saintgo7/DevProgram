# Rate API

## Description
Rate RESTful API implementation in Gin.

## Endpoints
- GET    /api/rate - Get all Rates
- GET    /api/rate/{id} - Get Rate by ID
- POST   /api/rate - Create new Rate
- PUT    /api/rate/{id} - Update Rate
- DELETE /api/rate/{id} - Delete Rate

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
