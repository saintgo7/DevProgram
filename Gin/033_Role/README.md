# Role API

## Description
Role RESTful API implementation in Gin.

## Endpoints
- GET    /api/role - Get all Roles
- GET    /api/role/{id} - Get Role by ID
- POST   /api/role - Create new Role
- PUT    /api/role/{id} - Update Role
- DELETE /api/role/{id} - Delete Role

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
