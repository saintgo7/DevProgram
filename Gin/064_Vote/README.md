# Vote API

## Description
Vote RESTful API implementation in Gin.

## Endpoints
- GET    /api/vote - Get all Votes
- GET    /api/vote/{id} - Get Vote by ID
- POST   /api/vote - Create new Vote
- PUT    /api/vote/{id} - Update Vote
- DELETE /api/vote/{id} - Delete Vote

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
