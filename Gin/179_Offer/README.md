# Offer API

## Description
Offer RESTful API implementation in Gin.

## Endpoints
- GET    /api/offer - Get all Offers
- GET    /api/offer/{id} - Get Offer by ID
- POST   /api/offer - Create new Offer
- PUT    /api/offer/{id} - Update Offer
- DELETE /api/offer/{id} - Delete Offer

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
