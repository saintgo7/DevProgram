# VAT API

## Description
VAT RESTful API implementation in Gin.

## Endpoints
- GET    /api/vat - Get all VATs
- GET    /api/vat/{id} - Get VAT by ID
- POST   /api/vat - Create new VAT
- PUT    /api/vat/{id} - Update VAT
- DELETE /api/vat/{id} - Delete VAT

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
