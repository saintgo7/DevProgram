# Blog API

## Description
Blog RESTful API implementation in Gin.

## Endpoints
- GET    /api/blog - Get all Blogs
- GET    /api/blog/{id} - Get Blog by ID
- POST   /api/blog - Create new Blog
- PUT    /api/blog/{id} - Update Blog
- DELETE /api/blog/{id} - Delete Blog

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
