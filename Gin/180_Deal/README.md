# Deal API

## Description
Deal RESTful API implementation in Gin.

## Endpoints
- GET    /api/deal - Get all Deals
- GET    /api/deal/{id} - Get Deal by ID
- POST   /api/deal - Create new Deal
- PUT    /api/deal/{id} - Update Deal
- DELETE /api/deal/{id} - Delete Deal

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
