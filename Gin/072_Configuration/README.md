# Configuration API

## Description
Configuration RESTful API implementation in Gin.

## Endpoints
- GET    /api/configuration - Get all Configurations
- GET    /api/configuration/{id} - Get Configuration by ID
- POST   /api/configuration - Create new Configuration
- PUT    /api/configuration/{id} - Update Configuration
- DELETE /api/configuration/{id} - Delete Configuration

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
