# Input API

## Description
Input RESTful API implementation in Gin.

## Endpoints
- GET    /api/input - Get all Inputs
- GET    /api/input/{id} - Get Input by ID
- POST   /api/input - Create new Input
- PUT    /api/input/{id} - Update Input
- DELETE /api/input/{id} - Delete Input

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
