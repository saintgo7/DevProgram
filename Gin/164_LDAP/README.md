# LDAP API

## Description
LDAP RESTful API implementation in Gin.

## Endpoints
- GET    /api/ldap - Get all LDAPs
- GET    /api/ldap/{id} - Get LDAP by ID
- POST   /api/ldap - Create new LDAP
- PUT    /api/ldap/{id} - Update LDAP
- DELETE /api/ldap/{id} - Delete LDAP

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
