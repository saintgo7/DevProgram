# Question API

## Description
Question RESTful API implementation in Gin.

## Endpoints
- GET    /api/question - Get all Questions
- GET    /api/question/{id} - Get Question by ID
- POST   /api/question - Create new Question
- PUT    /api/question/{id} - Update Question
- DELETE /api/question/{id} - Delete Question

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
