# Mapper API

## Description
Mapper RESTful API implementation in Gin.

## Endpoints
- GET    /api/mapper - Get all Mappers
- GET    /api/mapper/{id} - Get Mapper by ID
- POST   /api/mapper - Create new Mapper
- PUT    /api/mapper/{id} - Update Mapper
- DELETE /api/mapper/{id} - Delete Mapper

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
