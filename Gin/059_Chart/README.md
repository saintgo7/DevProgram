# Chart API

## Description
Chart RESTful API implementation in Gin.

## Endpoints
- GET    /api/chart - Get all Charts
- GET    /api/chart/{id} - Get Chart by ID
- POST   /api/chart - Create new Chart
- PUT    /api/chart/{id} - Update Chart
- DELETE /api/chart/{id} - Delete Chart

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
