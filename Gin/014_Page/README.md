# Page API

## Description
Page RESTful API implementation in Gin.

## Endpoints
- GET    /api/page - Get all Pages
- GET    /api/page/{id} - Get Page by ID
- POST   /api/page - Create new Page
- PUT    /api/page/{id} - Update Page
- DELETE /api/page/{id} - Delete Page

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
