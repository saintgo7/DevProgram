# Converter API

## Description
Converter RESTful API implementation in Gin.

## Endpoints
- GET    /api/converter - Get all Converters
- GET    /api/converter/{id} - Get Converter by ID
- POST   /api/converter - Create new Converter
- PUT    /api/converter/{id} - Update Converter
- DELETE /api/converter/{id} - Delete Converter

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
