# Tag API

## Description
Tag RESTful API implementation in Gin.

## Endpoints
- GET    /api/tag - Get all Tags
- GET    /api/tag/{id} - Get Tag by ID
- POST   /api/tag - Create new Tag
- PUT    /api/tag/{id} - Update Tag
- DELETE /api/tag/{id} - Delete Tag

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
