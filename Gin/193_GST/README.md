# GST API

## Description
GST RESTful API implementation in Gin.

## Endpoints
- GET    /api/gst - Get all GSTs
- GET    /api/gst/{id} - Get GST by ID
- POST   /api/gst - Create new GST
- PUT    /api/gst/{id} - Update GST
- DELETE /api/gst/{id} - Delete GST

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
