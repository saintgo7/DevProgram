# Cache API

## Description
Cache RESTful API implementation in Gin.

## Endpoints
- GET    /api/cache - Get all Caches
- GET    /api/cache/{id} - Get Cache by ID
- POST   /api/cache - Create new Cache
- PUT    /api/cache/{id} - Update Cache
- DELETE /api/cache/{id} - Delete Cache

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
