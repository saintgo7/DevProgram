# Promotion API

## Description
Promotion RESTful API implementation in Gin.

## Endpoints
- GET    /api/promotion - Get all Promotions
- GET    /api/promotion/{id} - Get Promotion by ID
- POST   /api/promotion - Create new Promotion
- PUT    /api/promotion/{id} - Update Promotion
- DELETE /api/promotion/{id} - Delete Promotion

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
