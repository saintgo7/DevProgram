# Table API

## Description
Table RESTful API implementation in Gin.

## Endpoints
- GET    /api/table - Get all Tables
- GET    /api/table/{id} - Get Table by ID
- POST   /api/table - Create new Table
- PUT    /api/table/{id} - Update Table
- DELETE /api/table/{id} - Delete Table

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
