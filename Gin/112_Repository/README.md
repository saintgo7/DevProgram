# Repository API

## Description
Repository RESTful API implementation in Gin.

## Endpoints
- GET    /api/repository - Get all Repositorys
- GET    /api/repository/{id} - Get Repository by ID
- POST   /api/repository - Create new Repository
- PUT    /api/repository/{id} - Update Repository
- DELETE /api/repository/{id} - Delete Repository

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
