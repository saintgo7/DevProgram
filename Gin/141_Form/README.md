# Form API

## Description
Form RESTful API implementation in Gin.

## Endpoints
- GET    /api/form - Get all Forms
- GET    /api/form/{id} - Get Form by ID
- POST   /api/form - Create new Form
- PUT    /api/form/{id} - Update Form
- DELETE /api/form/{id} - Delete Form

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
