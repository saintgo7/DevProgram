# Plugin API

## Description
Plugin RESTful API implementation in Gin.

## Endpoints
- GET    /api/plugin - Get all Plugins
- GET    /api/plugin/{id} - Get Plugin by ID
- POST   /api/plugin - Create new Plugin
- PUT    /api/plugin/{id} - Update Plugin
- DELETE /api/plugin/{id} - Delete Plugin

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
