# Refund API

## Description
Refund RESTful API implementation in Gin.

## Endpoints
- GET    /api/refund - Get all Refunds
- GET    /api/refund/{id} - Get Refund by ID
- POST   /api/refund - Create new Refund
- PUT    /api/refund/{id} - Update Refund
- DELETE /api/refund/{id} - Delete Refund

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
