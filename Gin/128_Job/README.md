# Job API

## Description
Job RESTful API implementation in Gin.

## Endpoints
- GET    /api/job - Get all Jobs
- GET    /api/job/{id} - Get Job by ID
- POST   /api/job - Create new Job
- PUT    /api/job/{id} - Update Job
- DELETE /api/job/{id} - Delete Job

## Usage
```bash
go run main.go
```

## Features
- RESTful API design
- CRUD operations
- Gin best practices
- JSON responses
