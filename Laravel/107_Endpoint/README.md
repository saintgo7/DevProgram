# Endpoint API

## Description
Endpoint RESTful API implementation in Laravel.

## Endpoints
- GET    /api/endpoint - Get all Endpoints
- GET    /api/endpoint/{id} - Get Endpoint by ID
- POST   /api/endpoint - Create new Endpoint
- PUT    /api/endpoint/{id} - Update Endpoint
- DELETE /api/endpoint/{id} - Delete Endpoint

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
