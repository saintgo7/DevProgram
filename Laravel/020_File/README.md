# File API

## Description
File RESTful API implementation in Laravel.

## Endpoints
- GET    /api/file - Get all Files
- GET    /api/file/{id} - Get File by ID
- POST   /api/file - Create new File
- PUT    /api/file/{id} - Update File
- DELETE /api/file/{id} - Delete File

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
