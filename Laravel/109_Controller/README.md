# Controller API

## Description
Controller RESTful API implementation in Laravel.

## Endpoints
- GET    /api/controller - Get all Controllers
- GET    /api/controller/{id} - Get Controller by ID
- POST   /api/controller - Create new Controller
- PUT    /api/controller/{id} - Update Controller
- DELETE /api/controller/{id} - Delete Controller

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
