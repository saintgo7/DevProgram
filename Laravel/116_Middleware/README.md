# Middleware API

## Description
Middleware RESTful API implementation in Laravel.

## Endpoints
- GET    /api/middleware - Get all Middlewares
- GET    /api/middleware/{id} - Get Middleware by ID
- POST   /api/middleware - Create new Middleware
- PUT    /api/middleware/{id} - Update Middleware
- DELETE /api/middleware/{id} - Delete Middleware

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
