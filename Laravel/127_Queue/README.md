# Queue API

## Description
Queue RESTful API implementation in Laravel.

## Endpoints
- GET    /api/queue - Get all Queues
- GET    /api/queue/{id} - Get Queue by ID
- POST   /api/queue - Create new Queue
- PUT    /api/queue/{id} - Update Queue
- DELETE /api/queue/{id} - Delete Queue

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
