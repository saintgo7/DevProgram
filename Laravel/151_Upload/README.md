# Upload API

## Description
Upload RESTful API implementation in Laravel.

## Endpoints
- GET    /api/upload - Get all Uploads
- GET    /api/upload/{id} - Get Upload by ID
- POST   /api/upload - Create new Upload
- PUT    /api/upload/{id} - Update Upload
- DELETE /api/upload/{id} - Delete Upload

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
