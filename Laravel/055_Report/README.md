# Report API

## Description
Report RESTful API implementation in Laravel.

## Endpoints
- GET    /api/report - Get all Reports
- GET    /api/report/{id} - Get Report by ID
- POST   /api/report - Create new Report
- PUT    /api/report/{id} - Update Report
- DELETE /api/report/{id} - Delete Report

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
