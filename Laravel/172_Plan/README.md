# Plan API

## Description
Plan RESTful API implementation in Laravel.

## Endpoints
- GET    /api/plan - Get all Plans
- GET    /api/plan/{id} - Get Plan by ID
- POST   /api/plan - Create new Plan
- PUT    /api/plan/{id} - Update Plan
- DELETE /api/plan/{id} - Delete Plan

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
