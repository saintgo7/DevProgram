# Builder API

## Description
Builder RESTful API implementation in Laravel.

## Endpoints
- GET    /api/builder - Get all Builders
- GET    /api/builder/{id} - Get Builder by ID
- POST   /api/builder - Create new Builder
- PUT    /api/builder/{id} - Update Builder
- DELETE /api/builder/{id} - Delete Builder

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
