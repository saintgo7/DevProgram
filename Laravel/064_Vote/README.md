# Vote API

## Description
Vote RESTful API implementation in Laravel.

## Endpoints
- GET    /api/vote - Get all Votes
- GET    /api/vote/{id} - Get Vote by ID
- POST   /api/vote - Create new Vote
- PUT    /api/vote/{id} - Update Vote
- DELETE /api/vote/{id} - Delete Vote

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
