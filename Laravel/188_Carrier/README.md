# Carrier API

## Description
Carrier RESTful API implementation in Laravel.

## Endpoints
- GET    /api/carrier - Get all Carriers
- GET    /api/carrier/{id} - Get Carrier by ID
- POST   /api/carrier - Create new Carrier
- PUT    /api/carrier/{id} - Update Carrier
- DELETE /api/carrier/{id} - Delete Carrier

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
