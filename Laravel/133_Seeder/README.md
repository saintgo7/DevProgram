# Seeder API

## Description
Seeder RESTful API implementation in Laravel.

## Endpoints
- GET    /api/seeder - Get all Seeders
- GET    /api/seeder/{id} - Get Seeder by ID
- POST   /api/seeder - Create new Seeder
- PUT    /api/seeder/{id} - Update Seeder
- DELETE /api/seeder/{id} - Delete Seeder

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
