# Sync API

## Description
Sync RESTful API implementation in Laravel.

## Endpoints
- GET    /api/sync - Get all Syncs
- GET    /api/sync/{id} - Get Sync by ID
- POST   /api/sync - Create new Sync
- PUT    /api/sync/{id} - Update Sync
- DELETE /api/sync/{id} - Delete Sync

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
