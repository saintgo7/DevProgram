# CreditCard API

## Description
CreditCard RESTful API implementation in Laravel.

## Endpoints
- GET    /api/creditcard - Get all CreditCards
- GET    /api/creditcard/{id} - Get CreditCard by ID
- POST   /api/creditcard - Create new CreditCard
- PUT    /api/creditcard/{id} - Update CreditCard
- DELETE /api/creditcard/{id} - Delete CreditCard

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
