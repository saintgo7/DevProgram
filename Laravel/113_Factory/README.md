# Factory API

## Description
Factory RESTful API implementation in Laravel.

## Endpoints
- GET    /api/factory - Get all Factorys
- GET    /api/factory/{id} - Get Factory by ID
- POST   /api/factory - Create new Factory
- PUT    /api/factory/{id} - Update Factory
- DELETE /api/factory/{id} - Delete Factory

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
