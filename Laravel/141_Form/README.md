# Form API

## Description
Form RESTful API implementation in Laravel.

## Endpoints
- GET    /api/form - Get all Forms
- GET    /api/form/{id} - Get Form by ID
- POST   /api/form - Create new Form
- PUT    /api/form/{id} - Update Form
- DELETE /api/form/{id} - Delete Form

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
