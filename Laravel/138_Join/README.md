# Join API

## Description
Join RESTful API implementation in Laravel.

## Endpoints
- GET    /api/join - Get all Joins
- GET    /api/join/{id} - Get Join by ID
- POST   /api/join - Create new Join
- PUT    /api/join/{id} - Update Join
- DELETE /api/join/{id} - Delete Join

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
