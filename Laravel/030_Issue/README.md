# Issue API

## Description
Issue RESTful API implementation in Laravel.

## Endpoints
- GET    /api/issue - Get all Issues
- GET    /api/issue/{id} - Get Issue by ID
- POST   /api/issue - Create new Issue
- PUT    /api/issue/{id} - Update Issue
- DELETE /api/issue/{id} - Delete Issue

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
