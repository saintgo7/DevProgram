# Backup API

## Description
Backup RESTful API implementation in Laravel.

## Endpoints
- GET    /api/backup - Get all Backups
- GET    /api/backup/{id} - Get Backup by ID
- POST   /api/backup - Create new Backup
- PUT    /api/backup/{id} - Update Backup
- DELETE /api/backup/{id} - Delete Backup

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
