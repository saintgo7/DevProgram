# Schema API

## Description
Schema RESTful API implementation in Laravel.

## Endpoints
- GET    /api/schema - Get all Schemas
- GET    /api/schema/{id} - Get Schema by ID
- POST   /api/schema - Create new Schema
- PUT    /api/schema/{id} - Update Schema
- DELETE /api/schema/{id} - Delete Schema

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
