# Address API

## Description
Address RESTful API implementation in Laravel.

## Endpoints
- GET    /api/address - Get all Addresss
- GET    /api/address/{id} - Get Address by ID
- POST   /api/address - Create new Address
- PUT    /api/address/{id} - Update Address
- DELETE /api/address/{id} - Delete Address

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
