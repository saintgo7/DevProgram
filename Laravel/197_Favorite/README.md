# Favorite API

## Description
Favorite RESTful API implementation in Laravel.

## Endpoints
- GET    /api/favorite - Get all Favorites
- GET    /api/favorite/{id} - Get Favorite by ID
- POST   /api/favorite - Create new Favorite
- PUT    /api/favorite/{id} - Update Favorite
- DELETE /api/favorite/{id} - Delete Favorite

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
