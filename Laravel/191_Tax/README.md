# Tax API

## Description
Tax RESTful API implementation in Laravel.

## Endpoints
- GET    /api/tax - Get all Taxs
- GET    /api/tax/{id} - Get Tax by ID
- POST   /api/tax - Create new Tax
- PUT    /api/tax/{id} - Update Tax
- DELETE /api/tax/{id} - Delete Tax

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
