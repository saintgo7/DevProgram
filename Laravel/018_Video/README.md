# Video API

## Description
Video RESTful API implementation in Laravel.

## Endpoints
- GET    /api/video - Get all Videos
- GET    /api/video/{id} - Get Video by ID
- POST   /api/video - Create new Video
- PUT    /api/video/{id} - Update Video
- DELETE /api/video/{id} - Delete Video

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
