# OAuth API

## Description
OAuth RESTful API implementation in Laravel.

## Endpoints
- GET    /api/oauth - Get all OAuths
- GET    /api/oauth/{id} - Get OAuth by ID
- POST   /api/oauth - Create new OAuth
- PUT    /api/oauth/{id} - Update OAuth
- DELETE /api/oauth/{id} - Delete OAuth

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
