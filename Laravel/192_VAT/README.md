# VAT API

## Description
VAT RESTful API implementation in Laravel.

## Endpoints
- GET    /api/vat - Get all VATs
- GET    /api/vat/{id} - Get VAT by ID
- POST   /api/vat - Create new VAT
- PUT    /api/vat/{id} - Update VAT
- DELETE /api/vat/{id} - Delete VAT

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
