# Criteria API

## Description
Criteria RESTful API implementation in Laravel.

## Endpoints
- GET    /api/criteria - Get all Criterias
- GET    /api/criteria/{id} - Get Criteria by ID
- POST   /api/criteria - Create new Criteria
- PUT    /api/criteria/{id} - Update Criteria
- DELETE /api/criteria/{id} - Delete Criteria

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
