# Option API

## Description
Option RESTful API implementation in Laravel.

## Endpoints
- GET    /api/option - Get all Options
- GET    /api/option/{id} - Get Option by ID
- POST   /api/option - Create new Option
- PUT    /api/option/{id} - Update Option
- DELETE /api/option/{id} - Delete Option

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
