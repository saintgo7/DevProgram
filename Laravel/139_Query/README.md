# Query API

## Description
Query RESTful API implementation in Laravel.

## Endpoints
- GET    /api/query - Get all Querys
- GET    /api/query/{id} - Get Query by ID
- POST   /api/query - Create new Query
- PUT    /api/query/{id} - Update Query
- DELETE /api/query/{id} - Delete Query

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
