# Job API

## Description
Job RESTful API implementation in Laravel.

## Endpoints
- GET    /api/job - Get all Jobs
- GET    /api/job/{id} - Get Job by ID
- POST   /api/job - Create new Job
- PUT    /api/job/{id} - Update Job
- DELETE /api/job/{id} - Delete Job

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
