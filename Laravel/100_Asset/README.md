# Asset API

## Description
Asset RESTful API implementation in Laravel.

## Endpoints
- GET    /api/asset - Get all Assets
- GET    /api/asset/{id} - Get Asset by ID
- POST   /api/asset - Create new Asset
- PUT    /api/asset/{id} - Update Asset
- DELETE /api/asset/{id} - Delete Asset

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
