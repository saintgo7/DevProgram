# Scheduler API

## Description
Scheduler RESTful API implementation in Laravel.

## Endpoints
- GET    /api/scheduler - Get all Schedulers
- GET    /api/scheduler/{id} - Get Scheduler by ID
- POST   /api/scheduler - Create new Scheduler
- PUT    /api/scheduler/{id} - Update Scheduler
- DELETE /api/scheduler/{id} - Delete Scheduler

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
