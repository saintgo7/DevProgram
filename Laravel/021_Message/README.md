# Message API

## Description
Message RESTful API implementation in Laravel.

## Endpoints
- GET    /api/message - Get all Messages
- GET    /api/message/{id} - Get Message by ID
- POST   /api/message - Create new Message
- PUT    /api/message/{id} - Update Message
- DELETE /api/message/{id} - Delete Message

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
