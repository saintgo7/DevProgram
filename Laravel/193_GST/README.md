# GST API

## Description
GST RESTful API implementation in Laravel.

## Endpoints
- GET    /api/gst - Get all GSTs
- GET    /api/gst/{id} - Get GST by ID
- POST   /api/gst - Create new GST
- PUT    /api/gst/{id} - Update GST
- DELETE /api/gst/{id} - Delete GST

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
