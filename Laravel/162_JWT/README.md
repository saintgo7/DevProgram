# JWT API

## Description
JWT RESTful API implementation in Laravel.

## Endpoints
- GET    /api/jwt - Get all JWTs
- GET    /api/jwt/{id} - Get JWT by ID
- POST   /api/jwt - Create new JWT
- PUT    /api/jwt/{id} - Update JWT
- DELETE /api/jwt/{id} - Delete JWT

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
