# Audio API

## Description
Audio RESTful API implementation in Laravel.

## Endpoints
- GET    /api/audio - Get all Audios
- GET    /api/audio/{id} - Get Audio by ID
- POST   /api/audio - Create new Audio
- PUT    /api/audio/{id} - Update Audio
- DELETE /api/audio/{id} - Delete Audio

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
