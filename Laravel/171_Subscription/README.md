# Subscription API

## Description
Subscription RESTful API implementation in Laravel.

## Endpoints
- GET    /api/subscription - Get all Subscriptions
- GET    /api/subscription/{id} - Get Subscription by ID
- POST   /api/subscription - Create new Subscription
- PUT    /api/subscription/{id} - Update Subscription
- DELETE /api/subscription/{id} - Delete Subscription

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
