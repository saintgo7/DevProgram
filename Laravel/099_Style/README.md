# Style API

## Description
Style RESTful API implementation in Laravel.

## Endpoints
- GET    /api/style - Get all Styles
- GET    /api/style/{id} - Get Style by ID
- POST   /api/style - Create new Style
- PUT    /api/style/{id} - Update Style
- DELETE /api/style/{id} - Delete Style

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
