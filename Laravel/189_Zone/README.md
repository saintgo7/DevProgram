# Zone API

## Description
Zone RESTful API implementation in Laravel.

## Endpoints
- GET    /api/zone - Get all Zones
- GET    /api/zone/{id} - Get Zone by ID
- POST   /api/zone - Create new Zone
- PUT    /api/zone/{id} - Update Zone
- DELETE /api/zone/{id} - Delete Zone

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
