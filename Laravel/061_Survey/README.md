# Survey API

## Description
Survey RESTful API implementation in Laravel.

## Endpoints
- GET    /api/survey - Get all Surveys
- GET    /api/survey/{id} - Get Survey by ID
- POST   /api/survey - Create new Survey
- PUT    /api/survey/{id} - Update Survey
- DELETE /api/survey/{id} - Delete Survey

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
