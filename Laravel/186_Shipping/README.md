# Shipping API

## Description
Shipping RESTful API implementation in Laravel.

## Endpoints
- GET    /api/shipping - Get all Shippings
- GET    /api/shipping/{id} - Get Shipping by ID
- POST   /api/shipping - Create new Shipping
- PUT    /api/shipping/{id} - Update Shipping
- DELETE /api/shipping/{id} - Delete Shipping

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
