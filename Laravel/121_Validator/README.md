# Validator API

## Description
Validator RESTful API implementation in Laravel.

## Endpoints
- GET    /api/validator - Get all Validators
- GET    /api/validator/{id} - Get Validator by ID
- POST   /api/validator - Create new Validator
- PUT    /api/validator/{id} - Update Validator
- DELETE /api/validator/{id} - Delete Validator

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
