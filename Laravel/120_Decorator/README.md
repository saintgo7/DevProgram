# Decorator API

## Description
Decorator RESTful API implementation in Laravel.

## Endpoints
- GET    /api/decorator - Get all Decorators
- GET    /api/decorator/{id} - Get Decorator by ID
- POST   /api/decorator - Create new Decorator
- PUT    /api/decorator/{id} - Update Decorator
- DELETE /api/decorator/{id} - Delete Decorator

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
