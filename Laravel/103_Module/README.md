# Module API

## Description
Module RESTful API implementation in Laravel.

## Endpoints
- GET    /api/module - Get all Modules
- GET    /api/module/{id} - Get Module by ID
- POST   /api/module - Create new Module
- PUT    /api/module/{id} - Update Module
- DELETE /api/module/{id} - Delete Module

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
