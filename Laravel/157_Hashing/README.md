# Hashing API

## Description
Hashing RESTful API implementation in Laravel.

## Endpoints
- GET    /api/hashing - Get all Hashings
- GET    /api/hashing/{id} - Get Hashing by ID
- POST   /api/hashing - Create new Hashing
- PUT    /api/hashing/{id} - Update Hashing
- DELETE /api/hashing/{id} - Delete Hashing

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
