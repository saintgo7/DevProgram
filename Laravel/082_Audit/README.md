# Audit API

## Description
Audit RESTful API implementation in Laravel.

## Endpoints
- GET    /api/audit - Get all Audits
- GET    /api/audit/{id} - Get Audit by ID
- POST   /api/audit - Create new Audit
- PUT    /api/audit/{id} - Update Audit
- DELETE /api/audit/{id} - Delete Audit

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
