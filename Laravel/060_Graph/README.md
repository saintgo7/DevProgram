# Graph API

## Description
Graph RESTful API implementation in Laravel.

## Endpoints
- GET    /api/graph - Get all Graphs
- GET    /api/graph/{id} - Get Graph by ID
- POST   /api/graph - Create new Graph
- PUT    /api/graph/{id} - Update Graph
- DELETE /api/graph/{id} - Delete Graph

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
