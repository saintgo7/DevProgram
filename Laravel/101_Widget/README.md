# Widget API

## Description
Widget RESTful API implementation in Laravel.

## Endpoints
- GET    /api/widget - Get all Widgets
- GET    /api/widget/{id} - Get Widget by ID
- POST   /api/widget - Create new Widget
- PUT    /api/widget/{id} - Update Widget
- DELETE /api/widget/{id} - Delete Widget

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
