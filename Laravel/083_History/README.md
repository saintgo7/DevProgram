# History API

## Description
History RESTful API implementation in Laravel.

## Endpoints
- GET    /api/history - Get all Historys
- GET    /api/history/{id} - Get History by ID
- POST   /api/history - Create new History
- PUT    /api/history/{id} - Update History
- DELETE /api/history/{id} - Delete History

## Usage
```bash
php artisan serve
```

## Features
- RESTful API design
- CRUD operations
- Laravel best practices
- JSON responses
