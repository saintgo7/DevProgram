# VAT API

## Description
VAT RESTful API implementation in Rocket.

## Endpoints
- GET    /api/vat - Get all VATs
- GET    /api/vat/{id} - Get VAT by ID
- POST   /api/vat - Create new VAT
- PUT    /api/vat/{id} - Update VAT
- DELETE /api/vat/{id} - Delete VAT

## Usage
```bash
cargo run
```

## Features
- RESTful API design
- CRUD operations
- Rocket best practices
- JSON responses
