# API API

## Description
API RESTful API implementation in Rocket.

## Endpoints
- GET    /api/api - Get all APIs
- GET    /api/api/{id} - Get API by ID
- POST   /api/api - Create new API
- PUT    /api/api/{id} - Update API
- DELETE /api/api/{id} - Delete API

## Usage
```bash
cargo run
```

## Features
- RESTful API design
- CRUD operations
- Rocket best practices
- JSON responses
