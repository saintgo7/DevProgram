# Widget API

## Description
Widget RESTful API implementation in Rocket.

## Endpoints
- GET    /api/widget - Get all Widgets
- GET    /api/widget/{id} - Get Widget by ID
- POST   /api/widget - Create new Widget
- PUT    /api/widget/{id} - Update Widget
- DELETE /api/widget/{id} - Delete Widget

## Usage
```bash
cargo run
```

## Features
- RESTful API design
- CRUD operations
- Rocket best practices
- JSON responses
