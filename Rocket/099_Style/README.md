# Style API

## Description
Style RESTful API implementation in Rocket.

## Endpoints
- GET    /api/style - Get all Styles
- GET    /api/style/{id} - Get Style by ID
- POST   /api/style - Create new Style
- PUT    /api/style/{id} - Update Style
- DELETE /api/style/{id} - Delete Style

## Usage
```bash
cargo run
```

## Features
- RESTful API design
- CRUD operations
- Rocket best practices
- JSON responses
