# Mapper API

## Description
Mapper RESTful API implementation in Rocket.

## Endpoints
- GET    /api/mapper - Get all Mappers
- GET    /api/mapper/{id} - Get Mapper by ID
- POST   /api/mapper - Create new Mapper
- PUT    /api/mapper/{id} - Update Mapper
- DELETE /api/mapper/{id} - Delete Mapper

## Usage
```bash
cargo run
```

## Features
- RESTful API design
- CRUD operations
- Rocket best practices
- JSON responses
