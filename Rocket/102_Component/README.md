# Component API

## Description
Component RESTful API implementation in Rocket.

## Endpoints
- GET    /api/component - Get all Components
- GET    /api/component/{id} - Get Component by ID
- POST   /api/component - Create new Component
- PUT    /api/component/{id} - Update Component
- DELETE /api/component/{id} - Delete Component

## Usage
```bash
cargo run
```

## Features
- RESTful API design
- CRUD operations
- Rocket best practices
- JSON responses
