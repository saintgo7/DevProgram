# Plugin API

## Description
Plugin RESTful API implementation in Rocket.

## Endpoints
- GET    /api/plugin - Get all Plugins
- GET    /api/plugin/{id} - Get Plugin by ID
- POST   /api/plugin - Create new Plugin
- PUT    /api/plugin/{id} - Update Plugin
- DELETE /api/plugin/{id} - Delete Plugin

## Usage
```bash
cargo run
```

## Features
- RESTful API design
- CRUD operations
- Rocket best practices
- JSON responses
