# Discount API

## Description
Discount RESTful API implementation in Rocket.

## Endpoints
- GET    /api/discount - Get all Discounts
- GET    /api/discount/{id} - Get Discount by ID
- POST   /api/discount - Create new Discount
- PUT    /api/discount/{id} - Update Discount
- DELETE /api/discount/{id} - Delete Discount

## Usage
```bash
cargo run
```

## Features
- RESTful API design
- CRUD operations
- Rocket best practices
- JSON responses
