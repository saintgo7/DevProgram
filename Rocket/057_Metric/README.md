# Metric API

## Description
Metric RESTful API implementation in Rocket.

## Endpoints
- GET    /api/metric - Get all Metrics
- GET    /api/metric/{id} - Get Metric by ID
- POST   /api/metric - Create new Metric
- PUT    /api/metric/{id} - Update Metric
- DELETE /api/metric/{id} - Delete Metric

## Usage
```bash
cargo run
```

## Features
- RESTful API design
- CRUD operations
- Rocket best practices
- JSON responses
