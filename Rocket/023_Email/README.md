# Email API

## Description
Email RESTful API implementation in Rocket.

## Endpoints
- GET    /api/email - Get all Emails
- GET    /api/email/{id} - Get Email by ID
- POST   /api/email - Create new Email
- PUT    /api/email/{id} - Update Email
- DELETE /api/email/{id} - Delete Email

## Usage
```bash
cargo run
```

## Features
- RESTful API design
- CRUD operations
- Rocket best practices
- JSON responses
