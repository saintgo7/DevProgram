# Poll API

## Description
Poll RESTful API implementation in Rocket.

## Endpoints
- GET    /api/poll - Get all Polls
- GET    /api/poll/{id} - Get Poll by ID
- POST   /api/poll - Create new Poll
- PUT    /api/poll/{id} - Update Poll
- DELETE /api/poll/{id} - Delete Poll

## Usage
```bash
cargo run
```

## Features
- RESTful API design
- CRUD operations
- Rocket best practices
- JSON responses
