# Coupon API

## Description
Coupon RESTful API implementation in Rocket.

## Endpoints
- GET    /api/coupon - Get all Coupons
- GET    /api/coupon/{id} - Get Coupon by ID
- POST   /api/coupon - Create new Coupon
- PUT    /api/coupon/{id} - Update Coupon
- DELETE /api/coupon/{id} - Delete Coupon

## Usage
```bash
cargo run
```

## Features
- RESTful API design
- CRUD operations
- Rocket best practices
- JSON responses
