# Worker API

## Description
Worker RESTful API implementation in Rocket.

## Endpoints
- GET    /api/worker - Get all Workers
- GET    /api/worker/{id} - Get Worker by ID
- POST   /api/worker - Create new Worker
- PUT    /api/worker/{id} - Update Worker
- DELETE /api/worker/{id} - Delete Worker

## Usage
```bash
cargo run
```

## Features
- RESTful API design
- CRUD operations
- Rocket best practices
- JSON responses
