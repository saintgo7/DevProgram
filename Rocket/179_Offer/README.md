# Offer API

## Description
Offer RESTful API implementation in Rocket.

## Endpoints
- GET    /api/offer - Get all Offers
- GET    /api/offer/{id} - Get Offer by ID
- POST   /api/offer - Create new Offer
- PUT    /api/offer/{id} - Update Offer
- DELETE /api/offer/{id} - Delete Offer

## Usage
```bash
cargo run
```

## Features
- RESTful API design
- CRUD operations
- Rocket best practices
- JSON responses
