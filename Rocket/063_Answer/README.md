# Answer API

## Description
Answer RESTful API implementation in Rocket.

## Endpoints
- GET    /api/answer - Get all Answers
- GET    /api/answer/{id} - Get Answer by ID
- POST   /api/answer - Create new Answer
- PUT    /api/answer/{id} - Update Answer
- DELETE /api/answer/{id} - Delete Answer

## Usage
```bash
cargo run
```

## Features
- RESTful API design
- CRUD operations
- Rocket best practices
- JSON responses
