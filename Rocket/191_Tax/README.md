# Tax API

## Description
Tax RESTful API implementation in Rocket.

## Endpoints
- GET    /api/tax - Get all Taxs
- GET    /api/tax/{id} - Get Tax by ID
- POST   /api/tax - Create new Tax
- PUT    /api/tax/{id} - Update Tax
- DELETE /api/tax/{id} - Delete Tax

## Usage
```bash
cargo run
```

## Features
- RESTful API design
- CRUD operations
- Rocket best practices
- JSON responses
