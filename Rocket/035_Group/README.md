# Group API

## Description
Group RESTful API implementation in Rocket.

## Endpoints
- GET    /api/group - Get all Groups
- GET    /api/group/{id} - Get Group by ID
- POST   /api/group - Create new Group
- PUT    /api/group/{id} - Update Group
- DELETE /api/group/{id} - Delete Group

## Usage
```bash
cargo run
```

## Features
- RESTful API design
- CRUD operations
- Rocket best practices
- JSON responses
