# Import API

## Description
Import RESTful API implementation in Rocket.

## Endpoints
- GET    /api/import - Get all Imports
- GET    /api/import/{id} - Get Import by ID
- POST   /api/import - Create new Import
- PUT    /api/import/{id} - Update Import
- DELETE /api/import/{id} - Delete Import

## Usage
```bash
cargo run
```

## Features
- RESTful API design
- CRUD operations
- Rocket best practices
- JSON responses
