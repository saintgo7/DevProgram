# Pusher API

## Description
Pusher RESTful API implementation in Rocket.

## Endpoints
- GET    /api/pusher - Get all Pushers
- GET    /api/pusher/{id} - Get Pusher by ID
- POST   /api/pusher - Create new Pusher
- PUT    /api/pusher/{id} - Update Pusher
- DELETE /api/pusher/{id} - Delete Pusher

## Usage
```bash
cargo run
```

## Features
- RESTful API design
- CRUD operations
- Rocket best practices
- JSON responses
