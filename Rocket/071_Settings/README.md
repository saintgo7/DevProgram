# Settings API

## Description
Settings RESTful API implementation in Rocket.

## Endpoints
- GET    /api/settings - Get all Settingss
- GET    /api/settings/{id} - Get Settings by ID
- POST   /api/settings - Create new Settings
- PUT    /api/settings/{id} - Update Settings
- DELETE /api/settings/{id} - Delete Settings

## Usage
```bash
cargo run
```

## Features
- RESTful API design
- CRUD operations
- Rocket best practices
- JSON responses
