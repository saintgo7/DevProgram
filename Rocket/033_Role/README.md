# Role API

## Description
Role RESTful API implementation in Rocket.

## Endpoints
- GET    /api/role - Get all Roles
- GET    /api/role/{id} - Get Role by ID
- POST   /api/role - Create new Role
- PUT    /api/role/{id} - Update Role
- DELETE /api/role/{id} - Delete Role

## Usage
```bash
cargo run
```

## Features
- RESTful API design
- CRUD operations
- Rocket best practices
- JSON responses
