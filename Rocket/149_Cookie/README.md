# Cookie API

## Description
Cookie RESTful API implementation in Rocket.

## Endpoints
- GET    /api/cookie - Get all Cookies
- GET    /api/cookie/{id} - Get Cookie by ID
- POST   /api/cookie - Create new Cookie
- PUT    /api/cookie/{id} - Update Cookie
- DELETE /api/cookie/{id} - Delete Cookie

## Usage
```bash
cargo run
```

## Features
- RESTful API design
- CRUD operations
- Rocket best practices
- JSON responses
