# Geography API

## Description
Geography RESTful API implementation in Rocket.

## Endpoints
- GET    /api/geography - Get all Geographys
- GET    /api/geography/{id} - Get Geography by ID
- POST   /api/geography - Create new Geography
- PUT    /api/geography/{id} - Update Geography
- DELETE /api/geography/{id} - Delete Geography

## Usage
```bash
cargo run
```

## Features
- RESTful API design
- CRUD operations
- Rocket best practices
- JSON responses
