# Export API

## Description
Export RESTful API implementation in Rocket.

## Endpoints
- GET    /api/export - Get all Exports
- GET    /api/export/{id} - Get Export by ID
- POST   /api/export - Create new Export
- PUT    /api/export/{id} - Update Export
- DELETE /api/export/{id} - Delete Export

## Usage
```bash
cargo run
```

## Features
- RESTful API design
- CRUD operations
- Rocket best practices
- JSON responses
