# Input API

## Description
Input RESTful API implementation in Rocket.

## Endpoints
- GET    /api/input - Get all Inputs
- GET    /api/input/{id} - Get Input by ID
- POST   /api/input - Create new Input
- PUT    /api/input/{id} - Update Input
- DELETE /api/input/{id} - Delete Input

## Usage
```bash
cargo run
```

## Features
- RESTful API design
- CRUD operations
- Rocket best practices
- JSON responses
