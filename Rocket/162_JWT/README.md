# JWT API

## Description
JWT RESTful API implementation in Rocket.

## Endpoints
- GET    /api/jwt - Get all JWTs
- GET    /api/jwt/{id} - Get JWT by ID
- POST   /api/jwt - Create new JWT
- PUT    /api/jwt/{id} - Update JWT
- DELETE /api/jwt/{id} - Delete JWT

## Usage
```bash
cargo run
```

## Features
- RESTful API design
- CRUD operations
- Rocket best practices
- JSON responses
