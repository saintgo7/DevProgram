# Module API

## Description
Module RESTful API implementation in Rocket.

## Endpoints
- GET    /api/module - Get all Modules
- GET    /api/module/{id} - Get Module by ID
- POST   /api/module - Create new Module
- PUT    /api/module/{id} - Update Module
- DELETE /api/module/{id} - Delete Module

## Usage
```bash
cargo run
```

## Features
- RESTful API design
- CRUD operations
- Rocket best practices
- JSON responses
