# Interceptor API

## Description
Interceptor RESTful API implementation in Rocket.

## Endpoints
- GET    /api/interceptor - Get all Interceptors
- GET    /api/interceptor/{id} - Get Interceptor by ID
- POST   /api/interceptor - Create new Interceptor
- PUT    /api/interceptor/{id} - Update Interceptor
- DELETE /api/interceptor/{id} - Delete Interceptor

## Usage
```bash
cargo run
```

## Features
- RESTful API design
- CRUD operations
- Rocket best practices
- JSON responses
