# Like API

## Description
Like RESTful API implementation in Rocket.

## Endpoints
- GET    /api/like - Get all Likes
- GET    /api/like/{id} - Get Like by ID
- POST   /api/like - Create new Like
- PUT    /api/like/{id} - Update Like
- DELETE /api/like/{id} - Delete Like

## Usage
```bash
cargo run
```

## Features
- RESTful API design
- CRUD operations
- Rocket best practices
- JSON responses
